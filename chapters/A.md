# 附录 A Python 运行环境与学习工具
> 用浏览器找到章节与示例，练习预测、运行和修改代码，再检查输出、进度和练习结果。

## A.1 从目录找到要读的内容

首页的课程目录按学习阶段排列。知道要读哪一章时，可以直接打开章节。想查某个概念或写法时，可以在搜索框输入“浅复制”“异常”或 `setdefault`，从匹配结果进入相关章节。

章节目录用于在全书中切换。进入一章后，用“本页目录”跳转到其中的小节。窄屏上可以展开章节目录和本页目录。查阅某个语法时，先读该小节的独立例子，再看章末怎样把它用回原任务。

## A.2 在网页里运行和修改示例

有运行按钮的代码框可以直接编辑。先读示例准备了哪些输入，再预测输出，然后点击“运行代码”或按 `Ctrl + Enter`。输出会显示在同一个代码框下方。

```python
message = "我的第一段 Python"
print(message)
```

先运行一次，核对输出与字符串内容。再修改 `message` 的值，保留 `print(message)`，观察哪一行决定输入、哪一行负责输出。使用“重置”可以恢复教材原来的示例，使用“复制”可以把当前代码粘贴到自己的练习记录中。

编辑的代码会保存在当前浏览器，刷新或返回时可以接着修改。遇到较长的代码行，可以用「自动换行」切换显示。第 6 章的练习有多个文件，用下拉菜单选文件，再运行整个项目。

| 练习动作 | 可以观察什么 |
| --- | --- |
| 先预测再运行 | 检查自己是否读懂表达式和执行顺序 |
| 只改一个输入 | 找到结果变化由哪一项数据引起 |
| 改一处判断或调用 | 比较两种写法的行为 |
| 重置后再运行 | 用原示例核对偏差来自哪里 |

示例使用网页上的 Python 运行环境，每次运行会重新准备一份练习环境。第 8、9 章中的文件在一次示例运行里创建、关闭和重新读取。若需要比较两次操作，可以把它们写在同一个代码框中，并分别输出结果。

## A.3 阅读输出和错误信息

输出面板中的文字可以来自 `print()`、测试运行器或错误报告。读输出时，先找最后一项结果，再沿着它的来源检查中间值。例如一个“空名单”的结果，可能来自初始化，也可能来自某条分支跳过了写入。

| 页面显示 | 接下来查看 |
| --- | --- |
| 正在加载浏览器中的 Python | 等待运行环境准备完成，之后再观察输出 |
| Python 加载失败或加载超时 | 刷新页面后重试，检查网络是否可用 |
| 出现异常类型和回溯 | 找到错误说明，再定位对应的代码和输入 |
| 程序运行超时 | 检查循环是否有终止条件，再运行一次 |
| 运行结束但没有输出 | 检查代码是否只是定义了对象，或是否需要调用和输出结果 |

示例可逐步添加少量输出帮助定位。例如先显示原文字和转换后的数值，再显示最后的计算结果。下面可以改变原文字，观察它是否真的能按预期转换。

```python
raw = " 18 "
value = int(raw)
print("原文字", repr(raw))
print("整数", value)
print("增加一项后的值", value + 1)
```

把输入换成 `"十八"` 后，转换会报告 `ValueError`。这是可以预期的练习结果。恢复数字文本后再运行，核对三个输出。更多错误类型和调试方法见[第 7 章 对象协作的可靠性](07.md)。

## A.4 做完一章后怎样回看

每章最后的练习可以先自己做，再展开参考解答。自测会给出反馈。答错时，可以回到对应小节，用一组更简单的数据重现规则，再重新作答。

“标记本章完成”会更新首页的学习进度。首页的「继续阅读」会打开上次读到的小节，手机上可以随时展开「本页目录」。进度和代码草稿保存在当前浏览器中。需要带到另一处时，可以保存章节链接和自己的练习结果。

继续阅读时，建议每章至少挑一项输入变化、一项边界情况和一项迁移任务。能先预测结果并解释原因，就可以尝试把学过的机制用到新的数据上。[附录 B 项目工具链与开发实践](B.md)
