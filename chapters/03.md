# 对象协作的流程控制
> 按报名请求到达的次序逐项处理，给出通过、重复和满员三种回执。

## 3.1 规则的顺序决定结果
一个活动最多接受 2 人。收到学号后先确认是否重复，再检查容量，通过时才更新名单。若名单已满且请求也是重复的，按本章约定返回“重复”。这项优先级属于问题规则。代码中的 if、elif、else 依次检查，执行第一个满足条件的分支。
for 从可迭代对象依次取得元素。下面先清除学号首尾空白。空学号跳过登记并给出解释。字典用来保存成功报名的次序和状态。尝试调换两个分支，比较最后一次请求的结果。

```python
capacity = 2
requests = ["S01", " ", "S02", "S03", "S01"]
accepted = {}

for raw in requests:
    student_id = raw.strip()
    if not student_id:
        print("空学号")
        continue
    if student_id in accepted:
        status = "重复"
    elif len(accepted) >= capacity:
        status = "满员"
    else:
        accepted[student_id] = "已报名"
        status = "通过"
    print(student_id, status)

print("最终名单", list(accepted))
```

每轮结束都应满足两个条件：人数不超过容量，学号互不重复。这些在循环前后始终成立的条件称为不变式。先检查再写入能够维持它们。使用第 9 章的报名模拟器，也可以观察同一规则下名单怎样随请求变化。

## 3.2 有终止条件的重复
知道要处理哪些元素时，优先用 for。要在某个条件维持时反复尝试，可以使用 while。写 while 时同时标明什么状态会推动它结束。break 立即结束循环，continue 转到下一轮。下面每次尝试都减少尝试余额，找到空位时提前结束。

```python
remaining_attempts = 3
available = [0, 0, 2]

while remaining_attempts > 0:
    index = len(available) - remaining_attempts
    remaining_attempts -= 1
    if available[index] > 0:
        print(f"第 {index + 1} 次查询有空位")
        break
else:
    print("暂未查到空位")
```

循环的 else 在没有通过 break 退出时执行。range(3) 依次给出 0、1、2。enumerate(requests, start=1) 可在遍历时同时取得序号与值。推导式适合写一个直接的映射或筛选，比如 [raw.strip() for raw in requests if raw.strip()]。如果还要更新多个对象并记录回执，用普通循环更清楚。

## 3.3 迭代与结构匹配
iter 得到迭代器，next 取下一项，元素耗尽后抛出 StopIteration。for 会管理这段过程。match 可以按照数据的结构提取字段，比如识别“报名 学号”或“退出”命令。最后放置通配分支 case _，处理其余形状。

```python
commands = iter(["报名 S01", "退出"])
while True:
    command = next(commands, "")
    match command.split():
        case ["报名", student_id]:
            print(f"准备登记 {student_id}")
        case ["退出"] | []:
            break
        case _:
            print("无法识别的命令")
```
