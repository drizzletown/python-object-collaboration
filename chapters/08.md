# 对象与外部环境的协作
> 将名单保存为 JSON，并为活动组织者生成可在表格软件中打开的 CSV。

## 8.1 约定文件内容与使用期限
内存名单在程序结束后消失。将它保存到文件前，先定义格式：活动编号为字符串，容量为非负整数，学生编号列表按成功报名的先后排列。JSON 适合保存这组带名字的字段，便于下次读取。CSV 适合按列交换名单，例如“活动编号、学号”，字段中含分隔符时交给 csv 模块转义。
pathlib.Path 表示文件系统中的路径。相对路径以当前工作目录为基准。用 path.parent.mkdir(parents=True, exist_ok=True) 可创建所需目录。以文本方式打开文件时明确使用 UTF-8，避免不同系统默认编码产生差异。模式 w 会截断原文件，应先选择正确路径并确认覆盖意图。

```python
import csv
import json
from pathlib import Path
from tempfile import TemporaryDirectory

event = {"id": "museum", "title": "博物馆", "capacity": 2, "students": ["S01", "S02"]}

with TemporaryDirectory() as folder:
    json_path = Path(folder) / "event.json"
    csv_path = Path(folder) / "roster.csv"

    with json_path.open("w", encoding="utf-8") as stream:
        json.dump(event, stream, ensure_ascii=False, indent=2)

    with json_path.open(encoding="utf-8") as stream:
        restored = json.load(stream)

    with csv_path.open("w", encoding="utf-8", newline="") as stream:
        writer = csv.writer(stream)
        writer.writerow(["活动编号", "学号"])
        writer.writerows((restored["id"], sid) for sid in restored["students"])

    print(restored["title"], len(restored["students"]))
    print(csv_path.read_text(encoding="utf-8").strip())
```

with 通过上下文管理器管理资源。进入文件块时获取文件对象，离开时关闭文件，包括块中抛出异常的情况。TemporaryDirectory 在块结束时清理临时目录，适合写可重复执行的示例。csv 模块自行处理记录换行，打开文件时传 newline=""。

## 8.2 读取成功以后仍需检查
json.load 可以确认文本是否是合法 JSON。像 {"capacity": -1, "students": []} 这样的内容仍需按业务契约验证。依次检查字段是否存在、类型是否合适、学生编号是否有效且唯一、名单长度是否超过容量。坏文件和从未创建的文件应得到不同处理：首次运行可以创建初始数据，读取损坏的数据时应保留现场并报告错误。
读取时可能遇到 FileNotFoundError、PermissionError、UnicodeDecodeError 和 JSONDecodeError。用少量代码说明每种错误在哪个边界处理。保存正式数据时，可把完整内容写到同一目录的临时文件，关闭后再用 Path.replace 替换目标，避免在序列化失败时提前截断旧文件。第 9 章会实际采用这一步骤。
