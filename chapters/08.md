# 对象与外部环境的协作
> 把活动状态保存为 JSON，重新读取并校验，再导出可用于表格软件的 CSV 名单。

## 8.1 关闭报名程序以后，名单在哪里

前几章的活动对象把名单保存在内存中。组织者结束本次工作后，下次打开程序还需要继续使用同一份名单。另一个需求是把名单交给负责签到的同学，在表格软件里查看。

- 输入是一场已登记 `S01`、`S02` 的博物馆活动，容量为 2。
- 保存活动名称、容量和报名顺序。恢复时从保存的记录重新取得这些数据，并验证名额与名单规则。
- 另外生成一份有表头的名单，每位参加者占一行，供表格软件导入。

这两份文件服务于不同任务。恢复时需要保留有名字的字段及其关系，导出时需要有稳定的行和列。先了解 Python 怎样使用文件资源和两种常见的数据格式。

## 8.2 用路径定位资源，用文件对象读写内容

### 路径怎样指向一个位置

`pathlib.Path` 表示文件系统中的路径。绝对路径从系统规定的位置开始，相对路径通常以当前工作目录为基准。`Path.cwd()` 返回当前工作目录。用 `/` 可以拼接路径段，`path.parent` 取得父目录。若需要创建中间目录，可用 `mkdir(parents=True, exist_ok=True)`。

### 打开文件时声明读写方式

| 模式 | 用途 | 对已有文件的影响 |
| --- | --- | --- |
| `"r"` | 读取，默认模式 | 保留内容，文件必须存在 |
| `"w"` | 写入，可创建新文件 | 打开时截断已有内容 |
| `"a"` | 追加，可创建新文件 | 将新内容加到末尾 |
| `"x"` | 创建新文件并写入 | 已存在时报告错误 |
| `"rb"` 或 `"wb"` | 按字节读写 | 读写规则沿用对应的 `r` 或 `w` |

文本模式负责在字符与字节之间转换，打开文本文件时可以指定 `encoding="utf-8"`。二进制模式直接读写字节。文件对象持有打开的资源，使用 `with` 可以在离开代码块时自动关闭文件，包括块内发生异常的情况。

```python
from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as folder:
    path = Path(folder) / "samples" / "notes.txt"
    path.parent.mkdir(parents=True, exist_ok=True)

    with path.open("x", encoding="utf-8") as stream:
        stream.write("第一条观察\n")
    print("文件已关闭", stream.closed)

    with path.open("a", encoding="utf-8") as stream:
        stream.write("第二条观察\n")

    print(path.read_text(encoding="utf-8").splitlines())
```

`TemporaryDirectory` 也由 `with` 管理，离开外层块时清理示例文件。`read_text` 适合一次读取整个小文件，内容较多时可以在打开文件的块内用 `for line in stream` 逐行读。[Python 官方文档的 pathlib](https://docs.python.org/3.12/library/pathlib.html)

## 8.3 用 JSON 保存结构化数据

JSON 把结构化数据写成文本。Python 的字典、列表、字符串、数字、布尔值和 `None` 可转换为对应的 JSON 对象、数组、字符串、数值、真假和 `null`。交换数据时宜使用字符串作为字典键，并事先约定必需字段与类型。

```python
import json

reading = {"地点": "东站", "温度": [18, 20], "已复核": True, "备注": None}
text = json.dumps(reading, ensure_ascii=False, indent=2)
print(text)

restored = json.loads(text)
print(restored["温度"][0], restored["已复核"])
```

`dumps` 和 `loads` 处理字符串，`dump` 和 `load` 处理打开的文件对象。`ensure_ascii=False` 让生成的文本直接显示中文，`indent=2` 便于阅读。自定义对象通常要先挑出要保存的字段，组成可序列化的数据。读取后再根据这些字段恢复对象或供其他组件使用。[Python 官方文档的 json](https://docs.python.org/3.12/library/json.html)

## 8.4 用 CSV 交换表格数据

CSV 以记录表示行，以字段表示列。可以用 `csv.writer` 和 `csv.reader` 逐行处理，也可以用 `DictWriter` 和 `DictReader` 按列名组织数据。字段内有逗号、引号或换行时，模块会按规则处理转义和引用。

```python
import csv
from io import StringIO

stream = StringIO(newline="")
writer = csv.DictWriter(stream, fieldnames=["地点", "读数"])
writer.writeheader()
writer.writerow({"地点": "东站, 门口", "读数": 18})

print(stream.getvalue().strip())
stream.seek(0)
row = next(csv.DictReader(stream))
print(row["地点"], int(row["读数"]) + 1)
```

`StringIO` 是内存中的文本流，可以像文件一样读写。写完后用 `seek(0)` 回到开头。上例中带逗号的地点保留在同一列，读数读取时仍是字符串，需要计算时再转换。用真实文件读写 CSV 时传入 `newline=""`，由 `csv` 管理记录的换行。[Python 官方文档的 csv](https://docs.python.org/3.12/library/csv.html)

## 8.5 在资源边界验证数据和错误

能打开文件、能解析格式、数据符合应用约定，是三个要分别验证的条件。例如，JSON 能把 `{"quantity": -1}` 解析为字典，使用库存数据的程序还需检查数量是否合法。

| 情形 | 可能出现的异常 | 调用者如何使用这个信息 |
| --- | --- | --- |
| 路径没有对应的文件 | `FileNotFoundError` | 首次启动时可按约定建立初始状态 |
| 当前操作没有足够权限 | `PermissionError` | 报告哪个资源无法访问 |
| 字节无法按指定编码解读 | `UnicodeDecodeError` | 确认文件编码，保留原文件供检查 |
| JSON 文本格式有误 | `json.JSONDecodeError` | 报告文件内容无法解析 |
| 数据类型或取值违反业务规则 | 校验函数报告的 `ValueError` | 报告具体字段或规则 |

保存已有状态时，可以先把完整内容写到同目录的临时文件，关闭后再替换目标。序列化失败时，原文件仍可读取。第 9 章用这一顺序实现文件存储，并用测试检查读取坏文件后的行为。

同样的协作思路也适用于其他外部接口。先约定如何取得资源、结果是什么格式，再判断结果能否进入业务流程。例如，调用网络服务读取数据时，调用方需要处理超时，并校验响应所带的字段。

## 8.6 回到案例 保存、恢复并导出报名名单

JSON 使用 `title`、`capacity` 和 `students` 三个字段。名单保留原报名顺序。恢复时检查标题、容量及每个学号，确认没有重复且人数不超限。CSV 从恢复后的数据生成，列名为“活动名称”和“学号”。

```python
import csv
import json
from pathlib import Path
from tempfile import TemporaryDirectory


def validate_event(data):
    required = {"title", "capacity", "students"}
    if not isinstance(data, dict) or not required <= data.keys():
        raise ValueError("活动数据缺少必需字段")

    title = data["title"]
    capacity = data["capacity"]
    students = data["students"]
    if not isinstance(title, str) or not title.strip():
        raise ValueError("活动名称须为非空字符串")
    if type(capacity) is not int or capacity < 0:
        raise ValueError("容量须为非负整数")
    if not isinstance(students, list):
        raise ValueError("名单须为列表")
    for student_id in students:
        if (
            not isinstance(student_id, str)
            or not student_id
            or student_id != student_id.strip()
        ):
            raise ValueError("名单中有格式不正确的学号")
    if len(set(students)) != len(students):
        raise ValueError("名单中有重复学号")
    if len(students) > capacity:
        raise ValueError("报名人数超过容量")
    return data


def load_event(path):
    with path.open(encoding="utf-8") as stream:
        data = json.load(stream)
    return validate_event(data)


def export_roster(event, path):
    with path.open("x", encoding="utf-8", newline="") as stream:
        writer = csv.writer(stream)
        writer.writerow(["活动名称", "学号"])
        for student_id in event["students"]:
            writer.writerow([event["title"], student_id])


event = {"title": "博物馆参观", "capacity": 2, "students": ["S01", "S02"]}
with TemporaryDirectory() as folder:
    json_path = Path(folder) / "event.json"
    csv_path = Path(folder) / "roster.csv"

    validated = validate_event(event)
    with json_path.open("x", encoding="utf-8") as stream:
        json.dump(validated, stream, ensure_ascii=False, indent=2)

    restored = load_event(json_path)
    print("恢复", restored["title"], restored["students"])
    export_roster(restored, csv_path)
    print(csv_path.read_text(encoding="utf-8").strip())

    invalid = dict(restored, students=["S01", "S01"])
    try:
        validate_event(invalid)
    except ValueError as error:
        print("拒绝非法名单", error)
```

运行后能看到恢复的两个学号、CSV 表头和两行数据，以及重复学号被拒绝的消息。示例在网页的一次运行里经历关闭文件和重新打开文件。临时目录会在运行结束时清理。
