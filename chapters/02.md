## 2.1 一次活动需要组织哪些数据

第 1 章用活动名称、容量和人数生成了一条报名提示。到了签到现场，组织者拿到的是一条条报名和签到记录。他们需要按学号查姓名，也要核对谁还没到。更新班级或活动配置时，还需要保留修改前的数据。

```text
任务：整理活动报名与签到数据
    1. 输入
        1.1 活动名称、容量 30、出发地和目的地。
        1.2 三条报名记录，学号为 S01、S02、S03。
        1.3 签到顺序为 S02、S01、S02。
    2. 处理
        2.1 根据学号查询报名记录，计算剩余名额。
        2.2 保留签到的先后和重复记录，核对已到与未到的报名者。
        2.3 在修改容量和班级前保留旧数据，检查哪些内容会跟着变化。
    3. 输出

```

按学号查人、按顺序回看记录、判断一个人是否到场，需要保留的数据关系各不相同。先从 Python 的容器类型入手，分别看每种关系怎样表示、查询和修改。

## 2.2 容器按什么关系组织对象

### 序列、映射和集合

容器本身也是对象，有类型和标识。容器通过引用组织其他对象。比如 `["蓝", "绿"]` 是一个列表对象，它的两个位置分别引用两个字符串对象。容器还可以引用其他容器，形成一条记录、一个表格或多层数据。

| 类型 | 创建举例 | 保存的关系 | 查找方式 | 原地修改 |
| --- | --- | --- | --- | --- |
| 列表 `list` | `["蓝", "绿", "蓝"]` | 有先后顺序，值可以重复 | 按下标读取，或按值查找 | 可以 |
| 元组 `tuple` | `(3, 4)` | 有先后顺序，各位置的引用固定 | 按下标读取，或按值查找 | 不能增删或替换位置 |
| 字典 `dict` | `{"x": 3, "y": 4}` | 一个键对应一个值，键唯一 | 按键读取 | 可以 |
| 集合 `set` | `{"蓝", "绿"}` | 记录唯一成员 | 判断成员是否存在 | 可以 |

列表和元组属于序列，字符串、字节序列也支持下标和切片。字典属于映射，键可以是字符串、整数或其他可哈希对象。同样写成 `data[0]`，对字典表示“查找键 0”，对列表和元组表示“取得第一项”。集合用来回答归属、交集和差集等问题。集合的遍历顺序没有保证。

### 四种容器的共同操作

| 操作 | 怎样理解 |
| --- | --- |
| `len(obj)` | 统计容器中的项。对字典是键值对的数量。 |
| `x in obj`、`x not in obj` | 检查某项是否存在。对字典检查的是键。 |
| `bool(obj)` | 空容器为假，非空容器为真。 |
| `a == b` | 比较内容。两个列表或两个元组须等长且各位置的值相等。字典比较键值对，集合比较成员。 |
| `a is b` | 检查两个引用是否指向同一个对象。 |

```python
colors = ["蓝", "绿", "蓝"]
by_code = {0: "绿", 1: "蓝"}
unique_colors = {"蓝", "绿"}

print("按位置取", colors[0])
print("按键取", by_code[0])
print("字典里查键", 0 in by_code, "蓝" in by_code)
print("字典里查值", "蓝" in by_code.values())
print("项数", len(colors), len(by_code), len(unique_colors))
print("空容器的真值", bool([]), bool(()), bool({}), bool(set()))
```

四种容器都可以逐项取数据。序列按位置，字典默认交出键，集合交出成员。第 3 章会用循环读取它们。这里先弄清每次取到的是什么对象。

## 2.3 序列的下标、切片与运算

### 取一项和取一段

下标从 0 开始，`seq[0]` 取第一项，`seq[-1]` 从末尾取最后一项。单个下标超出范围会产生 `IndexError`。切片写成 `seq[start:stop:step]`，从起点按步长取值，终点位置不包含在内。步长省略时是 1，负步长表示往回取，步长为零会产生 `ValueError`。省略起点时从取值方向的第一项开始，省略终点时可以取到另一端。

下表用 `values = [12, 7, 18, 7, 10]` 演示这些写法。

| 写法 | 取得的值 | 取值规则 |
| --- | --- | --- |
| `values[1]` | `7` | 取下标为 1 的元素 |
| `values[-1]` | `10` | 取最后一个元素 |
| `values[1:4]` | `[7, 18, 7]` | 取下标 1、2、3 |
| `values[:2]` | `[12, 7]` | 从开头取到下标 2 之前 |
| `values[-2:]` | `[7, 10]` | 从倒数第二项取到末尾 |
| `values[::2]` | `[12, 18, 10]` | 每隔一项取一个 |
| `values[::-1]` | `[10, 7, 18, 7, 12]` | 从末尾逐项向前取 |
| `values[4:10]` | `[10]` | 只取落在序列范围内的部分 |

`values[1]` 交出一个整数，`values[1:2]` 交出一个只含一项的列表。列表切片创建新的外层列表，所选元素仍来自原列表。对元组做同样的切片，结果是元组。

### 查询、连接和重复

`count(x)` 统计值 `x` 出现了几次，找不到时返回 0。`index(x)` 返回首次出现的位置，找不到时产生 `ValueError`。对同类型的列表或元组，`+` 把两个序列连接，`*` 按次数重复其中的元素引用。含有可变元素时，重复引用可能造成几处同时变化，稍后会做实验。

```python
values = [12, 7, 18, 7, 10]
print("一项与一段", values[1], values[1:2])
print("正向和反向切片", values[1:4], values[::-1])
print("出现次数与首个位置", values.count(7), values.index(7))
print("连接", values + [20])
print("重复", ("上", "下") * 2)
print("汇总", min(values), max(values), sum(values))
print("原列表", values)
```

对数值序列可以求和。求最大值、最小值和排序时，参与比较的值需要能确定先后。两个同类型的列表或元组也可以按顺序比较，先遇到的不同元素决定结果。例如 `[1, 9] < [2, 0]` 为真，因为第一项已经决定大小。[Python 官方文档的序列通用操作](https://docs.python.org/3.12/library/stdtypes.html#common-sequence-operations)

## 2.4 列表 按顺序保存和修改

### 创建列表并增加元素

用 `[]` 创建空列表，用 `[12, 7]` 创建带初始元素的列表。`list(...)` 可以把能逐项取值的对象转换为列表，例如 `list("ABC")` 得到三个字符组成的列表。一个列表可以存放不同类型的对象。后续需要对每项执行同类计算时，宜让元素具有相同用途并符合运算要求。

| 操作 | 对列表的影响 |
| --- | --- |
| `items.append(x)` | 把 `x` 作为一个元素加在末尾 |
| `items.extend(values)` | 逐项取出 `values` 中的值并追加 |
| `items.insert(i, x)` | 在指定位置之前插入一项 |
| `items[i] = x` | 替换指定位置的引用 |
| `items[i:j] = values` | 用一组元素替换一段，替换前后的长度可以不同 |

```python
with_group = ["蓝"]
with_group.append(["绿", "黄"])
print("把一组当作一项", with_group, len(with_group))

flat = ["蓝"]
flat.extend(["绿", "黄"])
flat.insert(1, "白")
flat[1:3] = ["紫"]
print("逐项加入后修改", flat, len(flat))
```

第一份列表的第二项仍是列表，外层长度为 2。第二份列表在加入后有三个颜色，插入“白”后有四项，用一个元素替换中间两项后得到 `["蓝", "紫", "黄"]`。看外层的元素形状，就能判断下一次下标访问会得到字符串还是列表。

### 按位置或值删除

| 操作 | 删除依据 | 结果 |
| --- | --- | --- |
| `items.pop(i)` | 下标。省略时取最后一项。 | 返回被删除的元素 |
| `items.remove(x)` | 值。删除第一项等于 `x` 的元素。 | 返回 `None` |
| `del items[i]`、`del items[i:j]` | 下标或切片 | `del` 语句不返回值 |
| `items.clear()` | 清空全部元素 | 返回 `None` |

`pop()` 在没有对应位置时产生 `IndexError`，例如对空列表取最后一项。`remove(x)` 在找不到该值时产生 `ValueError`。下例有两个相同的读数，可以观察按值删除时留下哪一个。

```python
readings = [18, 21, 18, 24, 26]
readings.remove(18)
print("删除第一个 18 后", readings)
last = readings.pop()
print("取走的末项", last)
del readings[1:3]
print("删除一段后", readings)
```

### 原地排序与新排序结果

`items.sort()` 在原列表上调整顺序，返回 `None`。`sorted(items)` 交出排好序的新列表，也可以接受元组、集合等可迭代对象。二者都能用 `reverse=True` 改为降序，用 `key` 指定比较依据。例如 `key=len` 把求长度的能力交给排序。键相同时，原来靠前的元素仍靠前。

```python
words = ["铅笔", "尺", "三角板", "橡皮"]
ordered = sorted(words, key=len)
print("按长度排出的新列表", ordered)
print("排序前的列表", words)

returned = words.sort(key=len, reverse=True)
print("原地降序", words)
print("sort 的返回值", returned)
```

`items.reverse()` 直接颠倒现有顺序。`list(reversed(items))` 则可取得一份倒序的新列表。`append()`、`extend()`、`sort()` 和 `reverse()` 都在原对象上工作，因此调用后继续用原来的名字读取数据。需要一份可独立增删的外层列表时，用 `items.copy()`。[Python 官方教程的列表方法](https://docs.python.org/3.12/tutorial/datastructures.html#more-on-lists)

## 2.5 元组 固定一组值的位置

### 创建、取值和解包

用 `()` 创建空元组，用 `(3, 4)` 表示一对坐标。只有一项时要保留逗号，`(3,)` 是元组，`(3)` 仍是整数。也可以用 `tuple([3, 4])` 创建元组。元组和列表一样支持下标、切片、`in`、`count()` 和 `index()`。

```python
point = (3, 4)
x, y = point
print("横纵坐标", x, y)
print("一项的类型", type((3,)).__name__, type((3)).__name__)

stations = ("起点", "东站", "西站", "终点")
first, *middle, last = stations
print("首尾", first, last)
print("中间的站点", middle)
```

解包把各位置的对象绑定给左边的名字。逐项解包要求名字和元素数量一致。带星号的名字接收剩余元素，得到列表。知道一组数据的固定含义时，可以用解包把它们赋给能说明用途的名字，例如 `x, y = point`。

### 固定的是外层位置

元组创建后，位置数量及各位置引用的对象都固定。可以把一个坐标重新绑定到另一个元组。若元组中的一项是列表，还可以通过该位置取得列表，并修改列表内部的内容。

```python
point = (3, 4)
previous = point
point = (5, 4)
print("新旧坐标", point, previous)

sample = ("上午", [18, 20])
readings = sample[1]
readings.append(21)
print("元组内的列表", sample)
print("引用仍指向同一个列表", sample[1] is readings)
```

固定结构的少量值适合用元组表示，例如横纵坐标。需要通过字段名识别含义时，可以用字典。元组也常用来组成一个复合键，例如用 `(行号, 列号)` 查找网格中的数据，这要求元组里的每一项都可哈希。[Python 官方教程的元组与序列](https://docs.python.org/3.12/tutorial/datastructures.html#tuples-and-sequences)

## 2.6 字典 用键定位一个值

### 创建键值关系

字典的每一项由键和值组成。用 `{}` 或 `dict()` 创建空字典，用 `{"x": 3, "y": 4}` 写出已有的键值对。`dict([("x", 3), ("y", 4)])` 可以把一组二元记录转换成字典。每个键只对应一个当前值，向已有的键赋值时会替换它关联的对象。

| 操作 | 结果 | 对字典的影响 |
| --- | --- | --- |
| `d[key]` | 返回指定键的值，缺键时产生 `KeyError` | 读取 |
| `key in d` | 判断键是否存在 | 读取 |
| `d.get(key, default)` | 有键时返回对应值，缺键时返回默认值。省略默认值时用 `None`。 | 读取 |
| `d[key] = value` | 为键建立或更新对应关系 | 新增或替换一项 |
| `d.setdefault(key, default)` | 有键时返回对应值，缺键时插入并返回默认值 | 可能新增一项 |

```python
stock = {"铅笔": 0, "尺": None}

print("已有且为零", stock.get("铅笔", 99))
print("查尺和纸", stock.get("尺"), stock.get("纸"))
print("尺和纸是否存在", "尺" in stock, "纸" in stock)

print("缺键时取默认值", stock.get("纸", 5))
print("查询后的键", list(stock))
print("缺键时存入默认值", stock.setdefault("纸", 5))
print("再次尝试设置", stock.setdefault("纸", 10))
print("已有的 None 也保留", stock.setdefault("尺", 10))
print("当前字典", stock)
```

库存为零的“铅笔”仍在字典中。“尺”对应的值恰好是 `None`，“纸”起初没有对应项，直接用 `get()` 查找时两者都得到 `None`。用 `in` 可以区分这两种状态。`get()` 只做查询，`setdefault()` 在键缺失时会插入数据。

### 批量更新、删除与读取视图

| 操作 | 用途 |
| --- | --- |
| `d.update(other)` | 把另一组键值对写入原字典，已有键采用新值 |
| `d \| other` | 合并两个字典，得到新字典。两边都有的键取右侧的值。 |
| `del d[key]` | 删除指定键值对。缺键时产生 `KeyError`。 |
| `d.pop(key, default)` | 删除指定键并交出原值。缺键时交出默认值，省略默认值则产生 `KeyError`。 |
| `d.popitem()` | 移除最后插入的一对键和值，并把它们作为元组交出。空字典会产生 `KeyError`。 |
| `d.clear()` | 清空原字典 |
| `d.copy()` | 新建一个含有相同键值引用的外层字典 |
| `dict.fromkeys(keys, value)` | 创建新字典，让这些键初始关联到同一个值。省略值时使用 `None`。 |

`keys()`、`values()`、`items()` 分别提供键、值、键值对的视图。视图会反映原字典的变化。`list(d)` 和 `list(d.keys())` 可以记录取得列表时有哪些键。`list(d.items())` 会把当前的键值对装入列表，值若引用可变对象，内层内容仍可能共享。

```python
defaults = {"颜色": "白", "高度": 10}
changes = {"高度": 12, "宽度": 20}

key_view = defaults.keys()
before = list(key_view)
combined = defaults | changes
print("合并结果", combined)
print("合并时的原字典", defaults)

defaults.update(changes)
print("当前的键和值", list(key_view), list(defaults.values()))
print("原来的键列表", before)
print("当前的键值对", list(defaults.items()))

removed = defaults.pop("宽度")
print("删去的值", removed)
print("再次查看键视图", list(key_view))
```

字典按插入顺序提供键值对。更新“高度”后，它仍在原来的位置，新插入的“宽度”排在末尾。删掉一个键再插入，它会成为最后插入的键。字典之间用 `==` 比较键和相应的值，插入次序可以不同。[Python 官方文档的字典类型](https://docs.python.org/3.12/library/stdtypes.html#mapping-types-dict)

### 哪些对象可以作为键

字典用键的散列值辅助定位，再用相等关系区分键。可哈希对象的散列值在其存续期间保持稳定。两个可哈希对象如果相等，它们的散列值也相同。散列值相同的两个对象仍可能有不同的值。集合对元素有同样的要求。

| 对象 | 能否用作键或集合成员 |
| --- | --- |
| 整数、布尔值、字符串 | 可以 |
| `(3, 4)` | 可以，各项均可哈希 |
| `(3, [4])` | 不可以，里面有列表 |
| `list`、`dict`、`set` 的实例 | 不可以，这几类内置容器不可哈希 |
| `frozenset` 的实例 | 可以，成员关系固定 |

```python
grid = {(1, 2): "入口", (3, 4): "出口"}
print("按两个坐标查找", grid[(3, 4)])

labels = {1: "整数"}
labels[True] = "已更新"
print("整数 1、浮点数 1.0 和 True", 1 == 1.0 == True)
print("键的个数", len(labels))
print("用 1.0 查值", labels[1.0])
```

上例中 `1`、`1.0` 与 `True` 彼此相等，所以访问的是同一个键所对应的值。设计编号时，可以让同类编号使用统一类型，避免不同含义的数据碰巧比较相等。字典的值可以引用列表或其他字典。[Python 官方术语表中的可哈希对象](https://docs.python.org/3.12/glossary.html#term-hashable)

## 2.7 集合 去重、查归属和比较成员

### 创建集合并维护成员

用 `{"蓝", "绿"}` 写出有成员的集合。空集合用 `set()` 创建，`{}` 创建的是空字典。`set(values)` 接收可迭代对象，把其中相等的成员合并成一项。集合支持 `in` 和 `len()`，取成员时可以遍历或排序后显示。

| 操作 | 怎样改变集合 |
| --- | --- |
| `s.add(x)` | 加入一个成员，已存在时保持原样 |
| `s.update(values)` | 逐项加入多个成员 |
| `s.discard(x)` | 删除指定成员，已缺失时可以继续执行 |
| `s.remove(x)` | 删除指定成员，缺失时产生 `KeyError` |
| `s.pop()` | 删除并交出一个任意成员，空集合会产生 `KeyError` |
| `s.clear()` | 清空集合 |

```python
colors = set(["蓝", "绿", "蓝"])
print("初始成员", sorted(colors))
colors.add("蓝")
colors.update(["白", "黄"])
colors.discard("黑")
colors.remove("绿")
print("更新后的成员", sorted(colors))
print("包含白色", "白" in colors)
```

再次加入“蓝”时，成员数没有变化。示例用 `sorted(colors)` 生成有固定显示顺序的列表，方便核对结果。

### 用集合运算得到关系

| 关系 | 运算符和方法 | 得到的成员 |
| --- | --- | --- |
| 交集 | `a & b`、`a.intersection(b)` | 两边都有 |
| 并集 | `a \| b`、`a.union(b)` | 至少一边有 |
| 差集 | `a - b`、`a.difference(b)` | 左边有，右边没有 |
| 对称差 | `a ^ b`、`a.symmetric_difference(b)` | 恰好一边有 |

这些写法会交出新的集合结果。想在原集合上保留交集，可以用 `a.intersection_update(b)` 或 `a &= b`。两个集合可以直接用运算符求交集。如果另一组数据是列表，可以先转成集合，也可以直接交给方法，例如 `a.intersection(["蓝", "黄"])`。

```python
left = {"蓝", "绿", "白"}
right = {"绿", "黄"}

print("交集", sorted(left & right))
print("并集", sorted(left | right))
print("左边独有", sorted(left - right))
print("右边独有", sorted(right - left))
print("只出现于一边", sorted(left ^ right))
print("用列表求交集", sorted(left.intersection(["蓝", "黄"])))
print("子集", {"绿"} <= left)
print("自己是否为自己的子集和真子集", left <= left, left < left)
print("两边是否没有共同成员", left.isdisjoint(right))
```

差集的方向决定保留哪一侧的成员。`a <= b` 检查 `a` 的成员是否都在 `b` 中，相等时也成立。`a < b` 还要求 `b` 有额外成员。`a >= b` 则检查 `a` 是否包含 `b` 的全部成员。`a.isdisjoint(b)` 在两者没有交集时为真。

### 用不可变集合表示固定的成员组合

`frozenset()` 创建不可变集合，可以做成员判断和集合运算，也可以作为字典的键。下面用颜色的成员组合查找配色方案。两次创建时给出的顺序不同，组成的集合仍相等。

```python
palettes = {frozenset(["蓝", "绿"]): "方案一"}
selected = frozenset(["绿", "蓝"])
print("选中的配色", palettes[selected])
```

[Python 官方文档的集合类型](https://docs.python.org/3.12/library/stdtypes.html#set-types-set-frozenset)

## 2.8 组合容器与转换数据

### 每一层保存一种关系

同一份数据常需要同时使用多种容器。例如用站名查站点，用一对坐标表示位置，用列表保留读数的先后。读取嵌套数据时，可以把每一步的结果先绑定给一个有含义的名字，再继续查询下一层。

```python
stations = {
    "东站": {"position": (3, 4), "readings": [18, 21]},
    "西站": {"position": (7, 2), "readings": [19]},
}

east = stations["东站"]
x, y = east["position"]
readings = east["readings"]
print("东站坐标", x, y)
print("东站最近一次读数", readings[-1])
print("东站读数条数", len(readings))
print("站点数量", len(stations))
```

`stations` 的值是记录字典，`east["readings"]` 的值是列表，`readings[-1]` 交出一个整数。数据量可以从记录本身推导，例如每次用 `len(readings)` 得到当前条数。这样增加一条读数后，统计就有同一份数据可依据。

### 转换时明确保留哪些信息

| 转换 | 保留的信息 |
| --- | --- |
| `list(seq)`、`tuple(seq)` | 元素及原来的先后顺序 |
| `set(seq)` | 唯一成员。原顺序和重复次数不再保存。 |
| `list(d)` 或 `set(d)` | 字典的键。列表保留键的插入顺序，集合用于成员运算。 |
| `list(d.items())` | 一组键值对，每一对是一个二元组 |
| `dict(pairs)` | 二元记录中的键值关系。键重复时采用后来读到的值。 |
| `list(dict.fromkeys(seq))` | 去掉重复值，按第一次出现的顺序保留各项。元素须可哈希。 |

```python
codes = ["B", "A", "B", "C"]
print("固定一组值", tuple(codes))
print("只看成员", sorted(set(codes)))
print("按首次出现顺序去重", list(dict.fromkeys(codes)))

pairs = [("东", 18), ("西", 21), ("东", 20)]
by_station = dict(pairs)
print("按站点查最新值", by_station["东"])
print("键值对", list(by_station.items()))
```

选择转换时，可以先写下需要保留的关系。例如只核对成员时可用集合，需要去重后仍按首次出现的顺序展示时可用字典保留次序。把列表转成元组只改变外层组织方式，里面的对象仍可能是可变的。

也可以看哪项查询最频繁。已知位置时，列表和元组可以直接按下标读取。按值检查成员时，列表和元组逐项比较，找到匹配项或查到末尾才结束。经常按编号查记录，或者反复判断某个成员是否存在，可以分别用字典和集合，让 Python 按散列值定位。

## 2.9 可变性、共享引用与复制

### 区分重新绑定与原地修改

`alias = original` 让两个名字指向同一个对象。执行 `original.append(x)` 会修改这个列表，经由 `alias` 也能看到新元素。执行 `original = original + [x]` 则先生成一个新列表，再让 `original` 指向它。`alias` 仍指向原先的列表。

```python
numbers = [10]
alias = numbers

numbers += [20]
print("原地追加后", numbers, alias, numbers is alias)

numbers = numbers + [30]
print("重新绑定后", numbers, alias, numbers is alias)
```

这里列表的 `+=` 原地扩展列表。元组是不可变的，用 `+=` 连接元组时会将左侧的名字重新绑定到连接结果。判断其他写法时，先确定它作用于名字、容器的某个位置，还是该位置引用的对象。例如 `rows[0] = [9]` 更换第一项的引用，`rows[0].append(9)` 修改第一项所引用的列表。

### 复制外层，还是同时复制内层

| 写法 | 外层容器 | 与原容器的内层关系 |
| --- | --- | --- |
| `alias = original` | 同一个外层对象 | 仍通过同一对象访问成员 |
| `shallow = original.copy()` | 新的外层对象 | 保留对原成员的引用 |
| `saved = deepcopy(original)` | 对本例会创建新的外层对象 | 嵌套的可变容器也会复制 |

列表、字典和集合的 `copy()` 都做浅复制。列表也可以用 `original[:]` 浅复制。标准库 `copy` 模块提供 `copy()` 和 `deepcopy()`。深复制会递归处理嵌套对象，例如为下面的字典创建副本。不可变的字符串和整数可以继续共享。

```python
from copy import deepcopy

original = [{"value": 1}]
alias = original
shallow = original.copy()
saved = deepcopy(original)

print("刚复制时内容相等", original == shallow == saved)
print("共享外层", alias is original, shallow is original, saved is original)
print("共享第一项", shallow[0] is original[0], saved[0] is original[0])

original.append({"value": 2})
original[0]["value"] = 9

print("三处列表的长度", len(alias), len(shallow), len(saved))
print("三处第一项的值", alias[0]["value"], shallow[0]["value"], saved[0]["value"])
```

浅副本的外层列表独立，所以追加后仍只有一项。浅副本与原列表的第一项引用同一个字典，因此两处的值都变为 9。深副本保留了修改前的长度和第一项的值。

复制前可以先指出将要修改哪一层。如果只换外层元素或增删键，浅复制已经能保留旧外层。如果只想为第一项保留独立的字典，可以先做 `saved = original.copy()`，再执行 `saved[0] = original[0].copy()`。需要同时保留多层嵌套的可变数据时，可用深复制。[Python 官方文档的浅复制与深复制](https://docs.python.org/3.12/library/copy.html)

### 同一对象可能出现在多个位置

`[[0, 0]] * 2` 重复的是对同一个列表的引用。修改一行，就会在两个位置看到同一份内容。要让每行可以单独修改，可以分别创建行列表。`dict.fromkeys(keys, [])` 同样会让多个键引用同一个列表，分别写出每个键的初始列表即可避免这种共享。

```python
shared_rows = [[0, 0]] * 2
shared_rows[0][1] = 9
print("重复引用的两行", shared_rows)

separate_rows = [[0, 0], [0, 0]]
separate_rows[0][1] = 9
print("分别创建的两行", separate_rows)

groups = dict.fromkeys(["甲", "乙"], [])
groups["甲"].append("读数 1")
print("两个键指向同一列表", groups)

groups = {"甲": [], "乙": []}
groups["甲"].append("读数 1")
print("每个键有自己的列表", groups)
```

`deepcopy()` 会记录已经复制的对象。若原结构中的两处引用同一行，深副本中的两处仍会引用同一份新行。需要各行独立时，创建数据时就要为每行分别建立对象。

## 2.10 回到案例 组织报名和签到数据

### 为每种数据关系选择容器

| 要做的事 | 选择 | 保留的数据关系 |
| --- | --- | --- |
| 读取活动名称、容量和路线 | 配置字典 | 根据字段名取值 |
| 识别出发地与目的地 | 路线元组 | 两个位置分别表示起点、终点 |
| 按学号查姓名和班级 | 报名字典，值也是字典 | 由学号找到记录，再按字段名查找 |
| 回看签到原始记录 | 签到列表 | 保留先后与重复 |
| 核对成员 | 从名单和签到记录取得集合 | 通过交集和差集确定到场、缺席和未报名的学号 |

报名人数从报名记录的数量计算。签到记录只要有更新，就能从原始列表再次计算出现过的学号。两项统计分别以自己的原始记录为依据。

```python
activity = {
    "name": "博物馆参观",
    "capacity": 30,
    "route": ("教学楼", "博物馆"),
}
registrations = {
    "S01": {"name": "林同学", "group": "一班"},
    "S02": {"name": "周同学", "group": "二班"},
    "S03": {"name": "吴同学", "group": "一班"},
}
arrival_order = ["S02", "S01", "S02"]

departure, destination = activity["route"]
enrolled_ids = set(registrations)
scanned_ids = set(arrival_order)
present = enrolled_ids & scanned_ids
missing = enrolled_ids - scanned_ids
unregistered = scanned_ids - enrolled_ids

print("活动", activity["name"])
print("路线", departure, "→", destination)
print("剩余名额", activity["capacity"] - len(registrations))
print("S02 姓名", registrations["S02"]["name"])
print("原始签到记录", arrival_order)
print("已到的报名者", sorted(present))
print("未签到的报名者", sorted(missing))
print("签到但未报名", sorted(unregistered))
```

运行后会查到 S02 是周同学，还剩 27 个名额。原始记录保留两次 S02，已到的报名者只有 S01 和 S02，未签到的是 S03。报名者集合减去签到集合用于找缺席者，反过来做差可找到未报名却有签到记录的人。

### 验证配置和名单的复制范围

活动配置的容量是整数，路线是由字符串组成的元组。浅复制可以保留调整容量前的配置。报名记录有两层字典。新增学号改变外层，编辑班级改变内层，因此要分别观察共享引用、浅副本和深副本。

```python
from copy import deepcopy

activity = {"name": "博物馆参观", "capacity": 30, "route": ("教学楼", "博物馆")}
old_config = activity.copy()
activity["capacity"] = 32
print("容量变更前后", old_config["capacity"], activity["capacity"])

registrations = {
    "S01": {"name": "林同学", "group": "一班"},
    "S02": {"name": "周同学", "group": "二班"},
    "S03": {"name": "吴同学", "group": "一班"},
}
shared = registrations
shallow = registrations.copy()
saved = deepcopy(registrations)

registrations["S04"] = {"name": "陈同学", "group": "二班"}
registrations["S01"]["group"] = "二班"

print("共享、浅复制、深复制的人数", len(shared), len(shallow), len(saved))
print("S01 的班级", shared["S01"]["group"], shallow["S01"]["group"], saved["S01"]["group"])
```

| 修改后核对 | 共享引用 `shared` | 浅复制 `shallow` | 深复制 `saved` |
| --- | --- | --- | --- |
| 新增 S04 后的人数 | 4 | 3 | 3 |
| 修改 S01 后看到的班级 | 二班 | 二班 | 一班 |

只想保留原来的学号顺序时，可以用 `list(registrations)` 取出键列表。需要同时保存原班级时，要复制到报名记录这一层。接下来若收到一个新学号，程序还要先检查它是否重复、是否有空位，再决定是否更新字典。[第 3 章 对象协作的流程控制](03.md)
