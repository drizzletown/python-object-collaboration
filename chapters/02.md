# 容器对象与数据组织
> 维护一批报名记录，按学号查找，并解释修改名单时其他引用会看到什么。

## 2.1 从单条信息到记录集合
只有一个 registered 数字，无法查明某位同学是否报名。把学号设计成字符串，便于保留前导零。字典可用唯一学号作为键，记录姓名等资料。列表适合保留签到次序，元组适合将一组固定字段一起返回，集合适合快速判断某学号是否出现以及计算差集。
容器的选择取决于后续操作。若记录需要按学号查询，用字典；若只需要知道参加者来自哪些班级，可以将班级名放进集合。集合元素和字典键必须可哈希；可变列表不能作为键。展示集合时可用 sorted 得到有确定顺序的列表。

```python
registrations = {
    "S01": {"name": "林同学", "group": "一班"},
    "S02": {"name": "周同学", "group": "二班"},
}
arrival_order = ["S02", "S01"]
checked_in = {"S02"}
missing = registrations.keys() - checked_in
first_two = arrival_order[:2]
route = ("教学楼", "博物馆")

print(registrations.get("S02")["name"])
print(sorted(missing))
print(first_two, route[1])
```

下标从 0 开始，切片左闭右开。空列表取 [0] 会抛出 IndexError。用字典下标访问缺失键会抛出 KeyError，get 可以提供一个默认值。例中 S02 已知存在，若由用户输入学号，应先检查 get 的结果再读取 name。

## 2.2 共享引用与可变性
列表和字典可原地修改。alias = roster 之后，两条名字指向同一个列表。roster.copy() 只复制外层列表，内部字典仍共享。元组的元素位置固定，位置上的引用仍可能指向可变对象。接口返回名单时，需要根据职责决定返回共享对象、只读结构或快照。

```python
roster = [{"id": "S01", "checked": False}]
alias = roster
snapshot = roster.copy()

roster[0]["checked"] = True
roster.append({"id": "S02", "checked": False})

print(len(alias), len(snapshot))
print(snapshot[0]["checked"])
print(alias is roster, snapshot is roster)
```

输出依次说明别名长度随原列表变为 2、快照外层长度仍是 1、共享的内部字典已经变化。如果这里只需要快照中的学号，可用 tuple(record["id"] for record in roster) 收集字符串。生成式会在第 3、4 章展开。
记录新增时，字典的相同键会被新值覆盖。要实现“重复报名应保留旧记录”，先判断 student_id in registrations，再决定是否赋值。第 3 章把这个判断写进完整流程。
