# 基础数据对象与信息处理
> 从一条报名提示出发，理解对象的值、类型和标识，学习名字绑定、数值与文字运算、类型转换和信息输出。

## 1.1 报名提示需要哪些信息

博物馆参观开放报名。活动最多容纳 30 人，目前有 28 人报名，每人门票 12.50 元。组织者要发布一条提示，让同学知道还剩几个名额，以及已报名同学的门票合计多少钱。

```text
任务：生成活动报名提示
    1. 输入
        1.1 活动名称、容量、已报名人数和每人票价。
    2. 处理
        2.1 用容量减去已报名人数，得到剩余名额。
        2.2 用已报名人数乘以每人票价，得到门票合计。
        2.3 将名称、名额、金额和单位组织成一句话。
    3. 输出
        3.1 博物馆参观：剩余 2 个名额，门票合计 350.00 元。
```

“28 人”和“学号 0028”看起来都有数字，却要做不同的工作。前者要参与计算，后者要保留原来的文字。票价要按分算清楚，输出时还要保留两位小数。把这些要求写清楚，才能为每项信息选择合适的对象和运算。

## 1.2 对象有值、类型和标识

### 三个问题分别问什么

Python 用对象表示程序中的数据。整数、字符串和布尔值都是对象。理解一个对象，可以分别问它的值是什么、属于什么类型、与另一处引用是否指向同一个对象。

| 要问的问题 | Python 中的观察方法 | 例子 |
| --- | --- | --- |
| 它表示什么值 | 显示或比较值 | `42 == 42.0` 为真 |
| 它是什么类型 | `type(value)` | `42` 是整数，`"42"` 是字符串 |
| 两处是否指向同一个对象 | `a is b`，也可观察 `id()` | `second = first` 后两处引用同一个对象 |

`type()` 返回实际类型对象。`isinstance()` 可以判断某对象是否属于一个类型或该类型的子类。`True` 的实际类型是 `bool`。由于 `bool` 是 `int` 的子类，`isinstance(True, int)` 也为真。选择数据时仍可根据含义把真假和数量分开表达。

```python
print(type(42).__name__, type("42").__name__)
print(type(1.5).__name__, type(True).__name__, type(None).__name__)
print("True 属于布尔类型", isinstance(True, bool))
print("True 也满足整数类型检查", isinstance(True, int))
```

### 标识和相等的关系

`id(obj)` 返回表示对象标识的整数。对象存续时标识保持稳定，同时存在的不同对象有不同标识。对象的存续结束后，标识可能被复用。用 `is` 直接判断标识关系，用 `==` 比较值。

```python
whole = 42
approximate = 42.0
same_reference = whole

print("数值相等", whole == approximate)
print("整数和浮点数是同一对象", whole is approximate)
print("两处引用同一整数", whole is same_reference)
print("三个标识", id(whole), id(approximate), id(same_reference))
```

观察第一行和第二行，可以看到“值相等”与“同一个对象”是两个问题。标识的具体数字由运行环境决定，只需核对第一、第三个标识相同。判断空值时常写 `result is None`，因为 `None` 是用来表示缺失的那个单一对象。[Python 官方文档的数据模型](https://docs.python.org/3.12/reference/datamodel.html#objects-values-and-types)

## 1.3 数值、布尔值和缺失值

### 按需要选择基础类型

| 类型 | 写法 | 典型任务 |
| --- | --- | --- |
| 整数 `int` | `42`、`-7`、`1_000` | 计数、序号、以分或厘米为单位的量 |
| 浮点数 `float` | `1.5`、`2.5e3` | 测量、比例、允许近似的小数 |
| 复数 `complex` | `2 + 3j` | 同时包含实部和虚部的计算 |
| 布尔值 `bool` | `True`、`False` | 记录一项条件是否成立 |
| 字符串 `str` | `"Python"`、`"0042"` | 文字和需要保留原样的编码 |
| 字节序列 `bytes` | `b"OK"` | 文件和通信中的原始字节 |
| 空值类型 `NoneType` | `None` | 结果尚未取得、某项数据缺失 |

整数可以写成十进制，也可以用 `0b`、`0o`、`0x` 开头写成二进制、八进制和十六进制。下划线可以分隔数字，方便阅读。`2.5e3` 表示 `2.5` 乘以 10 的三次方，写法中有小数点或指数时，这里得到的是浮点数。

```python
print("四种写法表示相同的整数", 42, 0b101010, 0o52, 0x2A)
print("大数按位分组", 1_000_000)
print("科学计数法", 2.5e3, 1.25e-2)

z = 3 + 4j
print("实部和虚部", z.real, z.imag)
print("与共轭复数相乘", z * (3 - 4j))
print("复数的模", abs(z))
```

实部和虚部可以分别读取。复数支持加减乘除、求模和相等比较。比较 `<`、`>` 需要一种大小顺序，Python 的复数没有这种运算。

### 浮点数为何出现微小误差

许多十进制小数在二进制浮点数中只能近似表示。近似值相加后，显示结果也可能与十进制心算不同。测量题可以事先确定允许的误差，用标准库的 `math.isclose()` 比较近似值。固定精度的金额或长度可以统一换成整数单位，再做加减乘除。

```python
from math import isclose

result = 0.1 + 0.2
print("浮点结果", result)
print("直接判等", result == 0.3)
print("按误差判断", isclose(result, 0.3))
print("以厘米计算", 10 + 20)
```

最后一行把 0.1 米和 0.2 米分别表示成 10 厘米和 20 厘米，求得 30 厘米。输出时可以再写成 0.30 米。控制显示的小数位数只影响生成的文字，原来的浮点对象仍是近似值。[Python 官方教程的浮点数说明](https://docs.python.org/3.12/tutorial/floatingpoint.html)

### 真假、零和缺失分别表示什么

数值零、空字符串和 `None` 都可以在真假判断中被当作假，含义仍然不同。零可以是一条已取得的读数，空字符串可能是用户交来的空文本，`None` 可以表示还没有取得读数。字符串 `"False"` 和 `"0"` 含有字符，用 `bool()` 检查都为真。

```python
reading = 0
unmeasured = None

print("零与缺失的真值", bool(reading), bool(unmeasured))
print("零是否缺失", reading is None)
print("未测量是否缺失", unmeasured is None)
print("文字是否为空", bool(""), bool("0"), bool("False"))
```

如果题目要判断是否取得读数，应检查是否为 `None`。如果题目要判断读数是否大于零，应写数值比较。先用自然语言分清两项任务，再选表达式。

## 1.4 字符串与字节序列

### 用字符串表示文字

单引号和双引号都能写字符串。可以用一种引号包住含有另一种引号的文字，用反斜线写换行 `\n`、制表 `\t`、反斜线 `\\` 等字符。字符串有顺序，支持 `len()`、下标、切片和成员判断。

```python
label = "站点：东站"
note = '他说："已完成。"'
lines = "第一行\n第二行"

print("字符数", len(label))
print("首尾字符", label[0], label[-1])
print("末尾的站名", label[-2:])
print("包含站名", "东站" in label)
print(note)
print(lines)
```

下标从 0 开始，负下标从末尾数。字符串的切片交出相应的文字片段。`"东站" in label` 查找的是连续的子串。字符串是不可变对象，若要更换其中的文字，可以用 `replace()` 生成替换后的结果。第 2 章会进一步解释序列的共同操作。

### 字节和文字通过编码转换

`str` 处理文字，`bytes` 处理字节。把文字编码为字节时，要指定编码。接收字节后，用相同的编码解读，才有可能还原原来的文字。`b"OK"` 可以直接写出常见 ASCII 字节，汉字通常用 `encode()` 得到字节序列。

```python
text = "东站"
data = text.encode("utf-8")
print("文字的长度", len(text))
print("UTF-8 的字节数", len(data))
print("首字节的整数值", data[0])
print("还原文字", data.decode("utf-8"))
```

“东站”是两个字符。在 UTF-8 中，这两个字符共占六个字节。对字节序列做下标访问，会得到一个 0 到 255 的整数。第 8 章会用同样的编码知识读写文本文件。[Python 官方文档的文本与二进制序列](https://docs.python.org/3.12/library/stdtypes.html#text-sequence-type-str)

## 1.5 名字怎样指向对象

### 先求右边，再绑定左边

执行 `number = 7` 时，Python 先取得右边表示的对象，再让左边的名字引用它。`previous = number` 让两个名字暂时引用同一个对象。执行 `number = number + 1` 时，先用旧值求和，再把 `number` 重新绑定到结果。

```python
number = 7
previous = number
print("初始时共享引用", number is previous)

number = number + 1
print("原来的值", previous)
print("当前的值", number)
print("现在共享引用", number is previous)
```

`previous` 仍指向 7。对整数而言，`number += 1` 同样计算结果并重新绑定。第 2 章会比较列表遇到 `+=` 时的行为。一个名字也可以先后指向不同类型的对象，`value = 7` 和 `value = "7"` 使用的是同一个名字，读到的值和可用的运算已经不同。

### 名字应表达用途和单位

名字可以由字母、数字和下划线等合法字符组成，首字符不能是数字。大小写有区别，`Count` 和 `count` 是两个名字。`if`、`for` 等关键字有固定的语言用途。平时可以用小写单词和下划线连接，`distance_cm` 表示以厘米为单位的距离，`has_reading` 表示是否取得读数。

```python
distance_cm = 125
distance_m = distance_cm / 100
raw_code = "0042"

print("数值和单位", distance_cm, distance_m)
print("编号保留原样", raw_code)
```

名字说明意图，类型由所引用的对象决定。给名字带上单位，有助于发现“以厘米计的距离”和“以米计的距离”混在同一个算式里的问题。

## 1.6 表达式怎样计算出新对象

### 算术运算和结果类型

表达式可以是一个字面量、一个名字，也可以由访问、调用和运算组成。每次求值会得到一个结果。例如，`10 - 3` 得到整数，`len("Python")` 得到文字的长度，`int("7")` 把数字文本转成整数。

| 运算 | 写法 | 结果或用途 |
| --- | --- | --- |
| 加减乘 | `7 + 2`、`7 - 2`、`7 * 2` | 两个整数得到整数 |
| 真除法 | `7 / 2` | 整数相除也得到浮点数 `3.5` |
| 向下取整除法 | `7 // 2` | 取不大于商的整数，这里为 `3` |
| 余数 | `7 % 2` | 与整除配对，这里为 `1` |
| 乘方 | `2 ** 3` | 求 2 的三次方 |
| 一元符号 | `-value` | 取得相反数 |

对于整数 `a` 和非零整数 `b`，有 `a == (a // b) * b + a % b`。所以 `-7 // 2` 为 `-4`，余数是 `1`。这与把 `-3.5` 直接转成整数时向零截断不同。`divmod(a, b)` 可以同时取得商和余数。

```python
print("普通除法、整除、取余", 7 / 2, 7 // 2, 7 % 2)
print("负数的整除和取余", -7 // 2, -7 % 2)
print("同时取得商和余数", divmod(-7, 2))
print("向零截断", int(-3.5))
print("整数与浮点数相加", 2 + 1.5)
```

整数和浮点数混合做常见算术时会得到浮点数。例如 `2 + 1.5` 得到 `3.5`。`//` 的“取整”描述的是数值，包含浮点数时结果仍可为浮点数，例如 `7.0 // 2` 为 `3.0`。

### 用优先级和括号说明分组

乘除、整除和取余优先于加减，乘方比乘除更早结合。连续乘方从右边结合。`-2 ** 2` 会先计算乘方，再取相反数。需要对负数底数乘方时写 `(-2) ** 2`。

```python
print("先乘后加", 2 + 3 * 4)
print("改变分组", (2 + 3) * 4)
print("连续乘方", 2 ** 3 ** 2)
print("符号的位置", -2 ** 2, (-2) ** 2)
```

前两行得到 14 和 20，最后一行得到 -4 和 4。读长表达式时，可以把某一部分的结果先交给有意义的名字，再写下一步。这样读者容易看出每次运算在解决什么问题。[Python 官方文档的运算优先级](https://docs.python.org/3.12/reference/expressions.html#operator-precedence)

### 用整数的位保存标志

整数还支持按位运算。`&` 在对应位都为 1 时保留 1，`|` 在至少一位为 1 时保留 1，`^` 在两位不同时保留 1。`<<`、`>>` 移动二进制位，`~` 按位取反。比如用第一个二进制位表示可读，用第三个位表示可导出，可以在一个整数中同时记录两项权限。

```python
can_read = 0b001
can_edit = 0b010
can_export = 0b100

permissions = can_read | can_export
print("组合后的二进制", bin(permissions))
print("可读", (permissions & can_read) != 0)
print("可编辑", (permissions & can_edit) != 0)
print("去掉可导出标志后的位", bin(permissions ^ can_export))
```

最后一行用异或翻转已打开的导出位。如果不确定原位的状态，可以用 `permissions & ~can_export` 清除该位。普通真假判断用 `and`、`or` 和 `not`，接下来会说明它们怎样求值。

## 1.7 比较、真假和短路

### 先分清在比较什么

| 需要判断 | 写法举例 | 结果 |
| --- | --- | --- |
| 值是否相等 | `amount == 42`、`amount != 42` | 按对象支持的相等规则比较 |
| 是否在范围内 | `0 <= score <= 100` | 同时满足两边的比较 |
| 是否是同一个对象 | `result is None`、`result is not None` | 比较标识 |
| 是否包含一段文字 | `"东站" in title` | 查找子串 |
| 多个条件怎样结合 | `ready and score >= 60` | 先检查左侧，再决定是否检查右侧 |

整数和浮点数可以按数值比较。文字和数字比较相等时按各自的类型规则处理，`"42" == 42` 为假。字符串之间按字符顺序逐项比较，因此 `"100" < "20"` 为真。若要按数值比较，从文本取得的数据需要先转换。

```python
score = 85

print("分数在范围内", 0 <= score <= 100)
print("是否合格", score >= 60)
print("按字符比较", "100" < "20")
print("按数值比较", int("100") < int("20"))
```

### and、or 和 not 怎样求值

`not x` 把 `x` 的真值反过来，得到布尔对象。`a and b` 在 `a` 为假时直接交出 `a`，否则求出并交出 `b`。`a or b` 在 `a` 为真时直接交出 `a`，否则求出并交出 `b`。能从左侧决定结果时，右侧就不再求值，这叫短路。

```python
reading = None
print("取得正数读数", reading is not None and reading > 0)

label = ""
print("空标题使用默认文字", label or "未命名")
print("零也会触发 or 的右侧", 0 or 100)
print("空标题的取反", not label)
```

第一行先确认读数存在，才会做大小比较。第二行用非空标题作为优先选择，标题为空时交出默认文字。零是有效值时，应根据是否缺失来选择默认值，例如检查 `reading is None`。优先级按比较和成员判断、`not`、`and`、`or` 的顺序，混合使用时可以用括号写清分组。

## 1.8 文字处理与类型转换

### 从一份文本得到可用的值

文本即使看起来像数字，仍然是字符串。先确认下一步需要哪种对象，再用相应的转换。整数转换要有整数字符串，带小数点的文本可以先用 `float()` 读成浮点数。对浮点数用 `int()` 会截去小数部分，是否允许丢掉小数要由任务决定。

| 操作 | 结果 | 常见边界 |
| --- | --- | --- |
| `int("42")` | 整数 `42` | `int("4.2")` 报 `ValueError` |
| `int(-4.2)` | 整数 `-4` | 向零截断 |
| `float("4.2")` | 浮点数 `4.2` | `float("四点二")` 报 `ValueError` |
| `str(42)` | 字符串 `"42"` | 结果用于显示和拼接 |
| `bool("False")` | `True` | 非空文字为真 |
| `int("2A", 16)` | 整数 `42` | 第二个参数指定进制 |

```python
raw_text = " 0042 "
cleaned = raw_text.strip()
number = int(cleaned)

print("保留编码", cleaned)
print("用文字拼接", cleaned + "1")
print("作为整数计算", number + 1)
print("把结果变回文字", str(number + 1) + " 个")
```

`cleaned` 仍保留两个前导零。`int(cleaned)` 得到数量 42，用于计算。转换后如果还要保留原样，应让原文本和转换值分别拥有自己的名字。收到不符合约定的文本时，先确认格式，再检查转换后的数值范围。第 7 章会处理失败路径。

### 清理、查找和替换文字

| 常用操作 | 用途 |
| --- | --- |
| `text.strip()` | 取得去掉首尾空白的文字 |
| `text.lower()`、`text.upper()` | 取得相应大小写的文字 |
| `text.startswith(prefix)`、`text.endswith(suffix)` | 检查开头或结尾 |
| `text.replace(old, new)` | 取得替换后的文字 |
| `text.split(separator)` | 按分隔符拆成几段 |
| `separator.join(parts)` | 用分隔符连接几段文字 |

```python
raw = "  East-03  "
cleaned = raw.strip()
updated = cleaned.lower().replace("-", "/")
parts = updated.split("/")

print("原文字", repr(raw))
print("清理后的文字", cleaned)
print("是否以 east 开头", updated.startswith("east"))
print("拆分后的各段", parts)
print("换一种分隔", " · ".join(parts))
```

原来的字符串仍可通过 `raw` 取得。上例每一步把新文字交给后续步骤使用。`split()` 返回列表，第 2 章会讲怎样读取它的各项。`repr()` 显示引号和必要的转义字符，便于检查首尾空白或换行。

## 1.9 让结果成为可读的信息

### print 接收对象，负责写出文字

`print()` 会把对象转换成文字，默认写入标准输出。在本网站，运行结果显示在代码框下方。多个对象默认用空格分隔，每次输出默认以换行结束。用 `sep` 选择分隔文字，用 `end` 选择末尾内容。

```python
name = "东站"
score = 85

print(name, score, sep="：")
print("分数", end="：")
print(score)

text = "甲\n乙"
print(str(text))
print(repr(text))
```

第一组输出用 `sep` 在名称和分数之间放入冒号。第二组用 `end` 让分数接在提示文字后面。`str(text)` 把换行作为正常文字输出，`repr(text)` 把换行显示成可以观察的转义形式。整理用户提示时用清楚的文字，排查文本格式时可以查看表示形式。

### 用格式化字符串安排字段

引号前写 `f`，花括号中的表达式会求值。冒号后可以写格式，指定进制、补零、位数或对齐。得到的结果是字符串，可以先保存，之后再决定何时输出。

| 写法 | 显示结果 | 用途 |
| --- | --- | --- |
| `f"{5:02d}"` | `"05"` | 整数不足两位时补零 |
| `f"{2.5:.2f}"` | `"2.50"` | 显示两位小数 |
| `f"{12500:,}"` | `"12,500"` | 对长数字分组 |
| `f"{0.375:.1%}"` | `"37.5%"` | 显示比例 |
| `f"{value!r}"` | 采用 `repr(value)` | 检查输入原样 |

```python
measured = 2.3456
quantity = 5
line = f"第 {quantity:02d} 条 · {measured:.2f} 米"

print(line)
print("仍可用原值计算", measured * 2)
print(f"合格比例 {3 / 8:.1%}")
```

第一行会显示 `2.35`，第二行仍用 `2.3456` 计算。可以先保留数值，在最后一步决定小数位数和单位。需要从输入取得文字时，真实程序也可以调用 `input()`。网页示例用可编辑的变量给出输入，修改赋值行即可重复试验。[Python 官方教程的输入与输出](https://docs.python.org/3.12/tutorial/inputoutput.html)

## 1.10 回到案例 生成并核对报名提示

### 选择类型并标明每步的结果

| 信息或中间结果 | 类型和单位 | 这样选择的原因 |
| --- | --- | --- |
| 活动名称 | 字符串 | 需要直接出现在通知里 |
| 容量、已报名、剩余 | 整数，单位为人 | 计数及相减 |
| 票价、门票合计 | 整数，单位为分 | 精确计算到分 |
| 提示中的金额与整条消息 | 字符串 | 金额需要两位小数，通知需要带单位 |

先约定收到的数量已经核对，报名人数在零到容量之间，票价为非负整数分。每人 12.50 元写成 1250 分，先用人数乘票价得到合计分数，再将 100 分换算为 1 元。算出来的元数和剩余分数一起组成金额文字。

```python
activity = "博物馆参观"
capacity = 30
registered = 28
ticket_cents = 1250

remaining = capacity - registered
total_cents = registered * ticket_cents
yuan = total_cents // 100
cents = total_cents % 100

amount = f"{yuan}.{cents:02d}"
message = f"{activity}：剩余 {remaining} 个名额，门票合计 {amount} 元。"
print(message)
```

`remaining` 为 2，`total_cents` 为 35000，`yuan` 为 350，`cents` 为 0。`:02d` 将 0 显示成 `00`，所以通知里的金额是 `350.00`。这几项可以分别检查。若金额文字不合预期，先确认合计分数，再检查换算和格式。

| 30 人、0 人、1250 分 | 30 | 0.00 元 |

| 32 人、32 人、980 分 | 0 | 313.60 元 |
