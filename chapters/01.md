# 基础数据对象与信息处理
> 从一条报名提示出发，学习基础对象的类型、标识和名字绑定，再用运算与格式化输出完成任务。

## 1.1 报名提示需要哪些信息

博物馆参观开放报名。活动最多容纳 30 人，目前有 28 人报名，每人门票 12.50 元。组织者想发一条提示，让同学知道还剩几个名额，以及已报名同学的门票合计多少钱。

先把任务分成输入、处理和输出。输入是活动名称、容量、已报名人数和每人票价。处理时，用容量减去报名人数得到剩余名额，用人数乘以票价得到总费用。最后，把名称和两个结果写进同一条提示。

用这组数据，提示需要包含活动名称、剩余 2 个名额和门票合计 350.00 元。这个任务涉及 Python 的几项通用能力：表示对象、绑定名字、求值和输出。

## 1.2 基础对象与类型

Python 用对象表示程序中的数据。整数 42、字符串「你好」和布尔值 `True` 都是对象。每个对象都有值、类型和标识。值是它表示的内容，类型决定它支持哪些操作，标识用来区分不同对象。

### 常见的基础对象

| 类型 | 写法举例 | 适合表示什么 |
| --- | --- | --- |
| 整数 `int` | `42`、`-7` | 数量、序号、以最小单位计数的量 |
| 浮点数 `float` | `1.5`、`0.1` | 测量值、比例等允许近似的数值 |
| 复数 `complex` | `2 + 3j` | 有实部和虚部的数，例如某些科学计算中的量 |
| 布尔值 `bool` | `True`、`False` | 条件成立或不成立 |
| 字符串 `str` | `"Python"`、`"0042"` | 文本、名称、带前导零的编码 |
| 字节序列 `bytes` | `b"OK"` | 以字节表示的数据，例如文件传输的内容 |
| 空值类型 `NoneType` | `None` | 信息缺失或结果尚未取得 |

选择类型时，可以先看这项信息要参与什么操作。数量 42 适合用整数表示，便于计算。编号 `"0042"` 适合用字符串表示，便于保留前导零。

许多十进制小数在浮点数中只能近似表示。需要精确到固定单位时，可以改用整数计数，例如把 1.25 米表示为 125 厘米。

### 用 type 查看对象的类型

```python
print(type(42), type("42"))
print(type(1.5), type(True), type(None))
```

第一行依次显示 `int` 和 `str`。整数 42 可以用于算术，带引号的 `"42"` 可以与另一段文字拼接。`type()` 返回对象的实际类型。`isinstance(对象, 类型)` 可以判断对象是否是指定类型或其子类的实例。例如，`bool` 是 `int` 的子类，`type(True)` 返回的具体类型是 `bool`。第 5 章会继续讨论类型与实例的关系。

## 1.3 对象标识和值

`id(对象)` 返回表示对象标识的整数。一个对象在存续期间的标识保持不变。同时存在的两个不同对象具有不同标识。对象结束后，标识可能被其他对象复用，因此它的唯一性限于对象的存续期。

判断两个对象时，有时关心它们的值是否相等，有时关心两处引用是否指向同一个对象。分别用 `==` 和 `is` 回答这两个问题。

```python
integer_value = 42
float_value = 42.0

print("整数对象的标识", id(integer_value))
print("浮点数对象的标识", id(float_value))
print("值相等", integer_value == float_value)
print("同一个对象", integer_value is float_value)
```

前两行的具体数字由运行环境决定。后两行分别是 `True` 和 `False`。整数 42 和浮点数 42.0 是两个不同类型的对象，它们的数值相等。比较数值或文字内容时用 `==`。检查一个名字是否指向空值对象时，可用 `result is None`，因为 `None` 是唯一的那个空值对象。[Python 数据模型](https://docs.python.org/3.12/reference/datamodel.html#objects-values-and-types)

## 1.4 名字绑定与重新绑定

执行 `number = 7` 时，Python 先求出等号右边的对象，再让左边的名字指向它。之后读取 `number`，得到的是它当前引用的对象。等号 `=` 建立绑定，双等号 `==` 比较值。

执行 `previous = number` 时，两个名字指向同一个整数对象。再执行 `number = number + 1`，右边先用原值算出 8，左边随后改为指向 8。

```python
number = 7
previous = number
print("最初指向同一个对象", number is previous)

number = number + 1
print("原来的值", previous)
print("当前的值", number)
print("现在指向同一个对象", number is previous)
```

`previous` 仍然指向 7。整数和字符串都是不可变对象，原对象的值在创建后保持不变。像 `number += 1` 这样的写法，对这里的整数名字而言，同样会算出新值并重新绑定。第 2 章会用可变容器说明直接修改对象时，共享引用会发生什么。

名字可以先后绑定到不同类型的对象。例如，`value = 7` 让 `value` 指向整数，随后执行 `value = "7"`，它就指向字符串。名字也可以说明数据的用途和单位，例如 `distance_cm` 表示以厘米为单位的距离。

## 1.5 对象的运算

表达式求值后会得到一个对象。它可以是单独的名字，也可以由运算符、索引、属性访问或调用组合而成。例如，`10 - 3` 得到整数，`7 < 10` 得到布尔值，`int("7")` 从文字得到整数。选择运算符时，需要同时看对象的类型和想得到的结果。

| 操作 | 常用写法 | 可以解决的问题 |
| --- | --- | --- |
| 算术 | `+ - * / // % **` | 求和、求差、求商、求余数和乘方 |
| 比较值 | `== != < <= > >=` | 检查两个值是否相等，或判断它们的大小关系 |
| 比较标识 | `is`、`is not` | 判断两个引用是否指向同一个对象 |
| 逻辑 | `not`、`and`、`or` | 取反、要求多个条件同时成立、满足任一条件即可 |
| 成员判断 | `in`、`not in` | 检查文字中是否包含某个词，或在容器中查找成员 |
| 访问与调用 | `text[0]`、`text[1:3]`、`text.strip()`、`len(text)` | 取得一项或一段内容，调用方法和函数 |
| 按位运算 | `&`、`\|`、`^`、`~`、`<<`、`>>` | 处理整数的二进制位，例如组合或检查标志 |

### 算术、结果类型与优先级

加、减、乘分别用 `+`、`-` 和 `*`。写在一个数前面的 `-` 表示取相反数。两个整数用 `/` 相除得到浮点数。`//` 表示商向下取整，`%` 得到与该商对应的余数，`**` 表示乘方。整数和浮点数混合做加法时，结果为浮点数。

```python
print("除法、向下取整和余数", 7 / 2, 7 // 2, 7 % 2)
print("负数的商和余数", -7 // 2, -7 % 2)
print("乘方、混合加法", 2 ** 3, 2 + 1.5)
print("两种分组", 2 + 3 * 4, (2 + 3) * 4)
```

`-7 // 2` 的结果是 -4，因为 -3.5 向下取整是 -4。最后一行得到 14 和 20。常用算术中，乘方优先于乘除，乘除和取余优先于加减。可以用括号改变分组，或把业务规则写得更清楚。连续乘方从右结合，`2 ** 3 ** 2` 相当于 `2 ** (3 ** 2)`。

### 值的比较与逻辑判断

用 `score >= 60` 可以检查分数是否达到 60。链式比较 `0 <= score <= 100` 同时检查下限和上限。整数和浮点数可以按数值比较。文字 `"42"` 与整数 `42` 用 `==` 比较得到 `False`。要按数值比较数字文字，先把它转换成数值。

可以用 `bool()` 查看一个对象在条件中的真假。数值零、空字符串和 `None` 都视为假。字符串 `"0"` 含有一个字符，所以视为真。`not` 将真假取反。`and` 先看左边，左边为假时直接返回左边的对象。`or` 也先看左边，左边为真时直接返回左边的对象。需要继续求值时，两者返回右边的对象。这样的求值方式叫短路。

```python
score = 85
submitted = True

print("分数有效", 0 <= score <= 100)
print("已提交且达到合格线", submitted and 60 <= score <= 100)

measurement = None
measurement_ready = measurement is not None and measurement > 0
print("取得正数测量值", measurement_ready)
```

把分数改成 59，第一行仍是 `True`，第二行变为 `False`。最后一条判断中，测量值是 `None`，左侧条件为假，Python 便跳过右侧的大小比较。在混合表达式中，比较、标识和成员判断先于逻辑运算，逻辑运算按 `not`、`and`、`or` 的优先级分组。[Python 表达式与运算优先级](https://docs.python.org/3.12/reference/expressions.html#operator-precedence)

### 字符串操作与类型转换

同一个符号会随对象类型表达不同的操作。例如，两个整数用 `+` 相加，两个字符串用 `+` 拼接。字符串乘以整数会重复文字。可以用 `in` 判断一段文字是否出现，用方括号取字符或切片。位置从 0 数起，切片右端的位置不包含在结果中。

从文本中取得的 `" 42 "` 是字符串。用 `strip()` 清理首尾空白后，可以用 `int()` 把它转换为整数。也可以用 `float()` 将小数字符串转换为浮点数，用 `str()` 把数字转换为供显示的文字。

```python
raw_text = " 42 "
cleaned = raw_text.strip()
number = int(cleaned)
word = "Python"

print("拼接文字", cleaned + "1")
print("整数相加", number + 1)
print("取前三个字符", word[:3])
print("包含 th", "th" in word)
```

前两行分别得到 421 和 43。把 `"四十二"` 交给 `int()` 会引发 `ValueError`，表示这段文字无法按所需格式转换。把整数和字符串直接用 `+` 混在一起会引发 `TypeError`。处理外部输入时，先确定目标类型，再转换并检查值的范围。第 7 章会介绍怎样应对这些错误。

## 1.6 将结果输出给读者

`print()` 会把传给它的对象转换成文本，默认写入标准输出。在本网站，结果显示在代码框下方。多个对象默认用空格分隔，每次输出默认以换行结束。用 `sep` 可以选择对象之间的分隔文字，用 `end` 可以指定末尾写入什么。

```python
name = "小林"
score = 85

print(name, score, sep="：")
print("分数", end="：")
print(score)

message = f"{name}的分数是 {score}。"
print(message)
```

当输出要按一句话组织时，可以先用格式化字符串生成文字，再交给 `print()`。引号前的 `f` 表示花括号里的表达式需要求值。还可以在花括号中指定显示格式。比如 `f"{2.5:.2f}"` 会显示成 `"2.50"`，`f"{5:02d}"` 会把整数 5 显示成 `"05"`。格式化得到的是一个字符串，计算仍然可以使用原来的数值对象。[Python 内置函数](https://docs.python.org/3.12/library/functions.html#print)

## 1.7 完成一条报名提示

回到博物馆参观的报名任务。给活动名称、容量、已报名人数和每人票价绑定名字，分别计算剩余名额与已报名者的总费用，最后生成一句可以直接发布的提示。这里使用已核对的数据，约定人数在零到容量之间。为精确到分，每人 12.50 元用整数 1250 分表示。

```python
activity = "博物馆参观"
capacity = 30
registered = 28
ticket_cents = 1250

remaining = capacity - registered
total_cents = registered * ticket_cents
yuan = total_cents // 100
cents = total_cents % 100

amount = f"{yuan}.{cents:02d}"
message = f"{activity}：剩余 {remaining} 个名额，门票合计 {amount} 元。"
print(message)
```

28 人的费用是 35000 分。用 `// 100` 得到 350 元，用 `% 100` 得到剩余 0 分，再把分补成两位。最后输出「博物馆参观：剩余 2 个名额，门票合计 350.00 元。」

如果门票尚未报价，可以先约定「按每人多少分计费」，用暂定价格验证计算和提示。正式报价到来后，再核对计价方式和单位，填入实际票价并重新运行。
