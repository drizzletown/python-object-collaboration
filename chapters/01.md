# 基础数据对象与信息处理
> 用活动名称、人数和票价表示一次活动，计算费用与剩余名额，生成一条报名提示。

## 1.1 把活动信息写成数据

博物馆参观开放报名，组织者想知道还能接受多少人，以及已报名同学的门票一共要花多少钱。先从一组已知信息开始。

- 活动名称是文字，用字符串表示。示例中的引号标出了字符串的起止位置。
- 活动容量和已报名人数用整数表示。约定两者都以人为单位，报名人数在零到容量之间。
- 票价也用整数表示，单位是分。每人 12.50 元，记为 1250 分。

先只解决名额问题。用容量减去已报名人数，再用 `print` 把活动名称和计算结果显示出来。

```python
activity = "博物馆参观"
capacity = 30
registered = 28

remaining = capacity - registered
print(activity, "剩余名额", remaining)
```

运行后会看到“博物馆参观 剩余名额 2”。把 `registered` 改成 30，再运行一次，看看结果怎样变化。

## 1.2 给对象绑定名字

在 `registered = 28` 中，28 是一个整数对象，`registered` 是引用它的名字。执行赋值语句时，Python 先算出等号右边的结果，再把左边的名字绑定到这个结果。后面的代码可以用 `registered` 取得当前的报名人数。

如果又有一位同学报名，可以用 `registered = registered + 1` 更新人数。右边使用更新前的 28 得到 29，左边的名字随后绑定到 29。

```python
registered = 28
previous_count = registered
registered = registered + 1

print("更新前", previous_count)
print("更新后", registered)
```

`previous_count` 仍引用原来的整数 28，所以两行依次显示 28 和 29。可以在示例末尾加上 `print(type(registered))` 查看对象的类型。比较两个值是否相等时，用两个等号 `==`，例如 `registered == 29` 会得到 `True`。

## 1.3 计算费用并生成报名提示

现在把费用加入同一条提示。用已报名人数乘以每人票价，得到总费用。计算时一直以分为单位，最后再用 `//` 求整元数、用 `%` 求剩余的分。这样可以精确保留每一分。

```python
activity = "博物馆参观"
capacity = 30
registered = 28
ticket_cents = 1250

remaining = capacity - registered
total_cents = registered * ticket_cents
yuan = total_cents // 100
cents = total_cents % 100

amount = f"{yuan}.{cents:02d}"
message = f"{activity}：剩余 {remaining} 个名额，门票合计 {amount} 元。"
print(message)
```

输出为「博物馆参观：剩余 2 个名额，门票合计 350.00 元。」字符串前的 `f` 让 Python 把花括号中的结果填入文字。`{cents:02d}` 把分显示成两位数字，例如 5 分显示为 05。

票价尚未确认时，可以先约定「票价按人计费，以分为单位」，用暂定票价写好并检验计算。收到正式报价后，再核对计价方式和单位，填入实际票价并重新运行。

## 1.4 从表单文字得到人数和判断结果

表单送来的人数可能是字符串，例如 `" 28 "`。用 `strip()` 去掉首尾空白，再用 `int()` 转成整数，才能参与人数计算。若收到的是无法转换的文字，Python 会报告转换错误。第 7 章会学习怎样处理这种情况。

有些信息要表达真假。用布尔值 `True` 表示预约成功，用 `False` 表示预约未获通过，用 `None` 表示结果尚未取得。可以用 `booking is None` 检查结果是否缺失。下面还用 `and` 连接两个要求，只有预约成功且人数低于容量时，才可以继续报名。

```python
raw_count = " 28 "
registered = int(raw_count.strip())
capacity = 30
booking = True

print("人数在允许范围内", 0 <= registered <= capacity)
print("可继续报名", booking is True and 0 <= registered < capacity)
```

两行最初都显示 `True`。把 `raw_count` 改为 `"30"`，再比较两行结果。人数正好达到容量时，这个人数仍然有效，继续报名的条件已经不成立。
