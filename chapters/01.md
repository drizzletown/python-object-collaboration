# 基础数据对象与信息处理
> 用人数、票价和确认状态表示一次活动，计算剩余名额并生成一行通知。

## 1.1 从需求识别数据
一次博物馆参观需要记录名称、容量、已报名人数和门票费用。写程序前先明确单位和取值范围。容量和人数用非负整数，金额用整数“分”，活动名称用字符串，是否确认预约用布尔值。预约尚无结果时，可以用 None 表示未知。此时“尚未确认”和“已确认不能预约”是不同状态。
赋值语句先计算右边的表达式，再把左边的名字绑定到结果对象。执行 registered = registered + 1 会读取原来的整数，计算新的整数，再重新绑定 registered。Python 对象有身份、类型和值。type(x) 可以查看类型，== 比较值是否相等，is 判断两个引用是否指向同一对象。检查未知状态时可写 booking is None。

```python
activity = "博物馆参观"
capacity = 30
registered = 28
ticket_cents = 1250
booking = None

remaining = capacity - registered
total_cents = registered * ticket_cents
yuan, cents = divmod(total_cents, 100)
print(f"{activity}还剩 {remaining} 个名额")
print(f"门票合计 {yuan}.{cents:02d} 元")
print("预约结果待确认：", booking is None)
print("可接受下一位报名：", registered < capacity)
```

例中剩余 2 个名额，总价 350.00 元。divmod 将金额分解为整元和余下的分，:02d 将分补足两位。先用括号表达计算顺序，再用格式化字符串拼成通知。/ 会产生浮点数，// 是向下取整除法，% 给出余数。金额示例先用整数计算，以便精确保留分。

## 1.2 用暂定票价编写预算规则
如果门票尚未报价，可以先建立假设：组织者会给出每人票价，单位为分，且金额非负。用暂定的 1250 分编写预算计算。正式报价到来后，确认价格是否按人计费、是否包含其他费用，再更新 ticket_cents 并核对总价。若报价按全班固定收费，计价规则也需要随之修订。

## 1.3 从文本得到可计算的数据
表单交给程序的数字可能是字符串。"28" + "1" 得到 "281"。使用 int("28") 后才可以把它用于人数运算。先 strip() 清理首尾空白，再转换。若输入是 "二十八"，int 会抛出 ValueError。第 7 章会处理这种失败；本章可以先写明前提“输入是十进制整数字符串，且人数在 0 到容量之间”。
当多个条件都成立才允许继续，可以用 and。这个表达式会从左到右检查条件，左侧为假时无需继续求值右侧。试把 booking 依次改成 True、False 和 None，比较两条输出的意义。

```python
raw_count = " 28 "
registered = int(raw_count.strip())
capacity = 30
booking = True

print(0 <= registered <= capacity)
print(booking is True and registered < capacity)
```
