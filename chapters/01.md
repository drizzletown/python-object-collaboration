# 基础数据对象与信息处理
> 从一条报名提示出发，学习基础对象的类型、标识和名字绑定，再用运算与格式化输出完成任务。

## 1.1 报名提示需要哪些信息

博物馆参观开放报名。活动最多容纳 30 人，目前有 28 人报名，每人门票 12.50 元。组织者想发一条提示，让同学知道还剩几个名额，以及已报名同学的门票合计多少钱。

先把任务分成输入、处理和输出。输入是活动名称、容量、已报名人数和每人票价。处理时，用容量减去报名人数得到剩余名额，用人数乘以票价得到总费用。最后，把名称和两个结果写进同一条提示。

先试着完成名额计算。把 `registered` 改成 30，再运行一次。

```python
activity = "博物馆参观"
capacity = 30
registered = 28

remaining = capacity - registered
print(activity, "剩余名额", remaining)
```

从这几行可以看出程序需要解决四件事。用对象表示文字和数字，给对象取名字，对对象进行运算，再把结果显示给读者。接下来逐一看 Python 怎样做这些工作。

## 1.2 基础对象与类型

Python 用对象表示程序中的数据。人数 28、活动名称「博物馆参观」、预约成功的判断结果，都可以作为对象使用。每个对象都有值、类型和标识。值是它表示的内容，类型决定它能参与哪些操作，标识用来区分不同对象。

### 常见的基础对象

| 类型 | 写法举例 | 适合表示什么 |
| --- | --- | --- |
| 整数 `int` | `28`、`1250` | 人数、数量、以分为单位的金额 |
| 浮点数 `float` | `1.5`、`12.50` | 用时、距离等允许近似的数值 |
| 复数 `complex` | `2 + 3j` | 有实部和虚部的数，例如某些科学计算中的量 |
| 布尔值 `bool` | `True`、`False` | 条件成立或不成立 |
| 字符串 `str` | `"博物馆参观"`、`"28"` | 名称、表单文字、带前导零的学号 |
| 字节序列 `bytes` | `b"OK"` | 以字节表示的数据，例如文件传输的内容 |
| 空值类型 `NoneType` | `None` | 信息缺失或结果尚未取得 |

同一信息可以用不同类型表示。用 28 表示人数，便于计算。用 `"0028"` 表示学号，便于保留前导零。选择类型时，先问后续需要对这项信息做什么。

整数可以精确表示整数值。许多十进制小数在浮点数中只能近似表示。因此，本章把每人 12.50 元记为整数 1250 分，先按分计算，到输出时再显示为元。预约状态则有三种情况。已确认用 `True`，未获通过用 `False`，尚无结果用 `None`。

### 用 type 查看对象的类型

```python
print(type(28), type("28"))
print(type(12.50), type(True), type(None))
```

第一行依次显示 `int` 和 `str`。数字 28 可以用于算术，带引号的 `"28"` 则可以与另一段文字拼接。`type()` 返回对象的实际类型。`isinstance(对象, 类型)` 还可以判断对象是否属于某个类型或它的子类。例如，`bool` 是 `int` 的子类，`type(True)` 返回的具体类型仍是 `bool`。第 5 章会继续讨论类型与实例的关系。

## 1.3 对象标识和值

`id(对象)` 返回表示对象标识的整数。一个对象在存续期间的标识保持不变。同时存在的两个不同对象具有不同标识。对象结束后，标识可能被其他对象复用，因此不适合拿来当长期保存的学号或记录编号。

判断两个对象时，有时关心它们的值是否相等，有时关心两处引用是否指向同一个对象。分别用 `==` 和 `is` 回答这两个问题。

```python
registered = 28
estimate = 28.0

print("整数对象的标识", id(registered))
print("浮点数对象的标识", id(estimate))
print("值相等", registered == estimate)
print("同一个对象", registered is estimate)
```

前两行的具体数字由运行环境决定。后两行分别是 `True` 和 `False`。整数 28 和浮点数 28.0 在数值上相等，却是两个不同类型的对象。比较人数、票价或文字内容时通常用 `==`。检查预约结果是否缺失时，可以用 `booking is None`，因为 `None` 是唯一的那个空值对象。[Python 数据模型](https://docs.python.org/3.12/reference/datamodel.html#objects-values-and-types)

## 1.4 名字绑定与重新绑定

执行 `registered = 28` 时，Python 先求出等号右边的对象，再让左边的名字指向它。之后读取 `registered`，得到的是它当前引用的对象。等号 `=` 建立绑定，双等号 `==` 比较值。

执行 `previous_count = registered` 时，两个名字指向同一个整数对象。再执行 `registered = registered + 1`，右边先用原人数算出 29，左边随后改为指向 29。

```python
registered = 28
previous_count = registered
print("最初指向同一个对象", registered is previous_count)

registered = registered + 1
print("原报名人数", previous_count)
print("现报名人数", registered)
print("现在指向同一个对象", registered is previous_count)
```

`previous_count` 仍然指向 28。整数和字符串都是不可变对象，原对象的值在创建后保持不变。像 `registered += 1` 这样的写法，对这里的整数名字而言，同样会算出新值并重新绑定。第 2 章会用可变容器说明直接修改对象时，共享引用会发生什么。

名字可以先后绑定到不同类型的对象。为了让含义容易读懂，可以用 `raw_count` 表示表单送来的文字，用 `registered` 表示转换后的整数人数。常用英文小写字母和下划线组织名字，例如 `ticket_cents` 同时交代了数据含义和单位。

## 1.5 对象的运算

表达式求值后会得到一个对象。它可以是单独的名字，也可以由运算符、索引、属性访问或调用组合而成。例如，`capacity - registered` 得到整数，`registered < capacity` 得到布尔值，`int(raw_count)` 尝试从文字得到整数。选择运算符时，需要同时看对象的类型和想得到的结果。

| 操作 | 常用写法 | 可以解决的问题 |
| --- | --- | --- |
| 算术 | `+ - * / // % **` | 计算费用、剩余名额、商和余数 |
| 比较值 | `== != < <= > >=` | 检查人数是否相等、是否达到上限 |
| 比较标识 | `is`、`is not` | 判断两个引用是否指向同一个对象 |
| 逻辑 | `not`、`and`、`or` | 取反、要求多个条件同时成立、满足任一条件即可 |
| 成员判断 | `in`、`not in` | 检查文字中是否包含某个词，或在容器中查找成员 |
| 访问与调用 | `text[0]`、`text[1:3]`、`text.strip()`、`len(text)` | 取得一项或一段内容，调用方法和函数 |
| 按位运算 | `&`、`\|`、`^`、`~`、`<<`、`>>` | 处理整数的二进制位，例如组合或检查标志 |

### 算术、结果类型与优先级

加、减、乘分别用 `+`、`-` 和 `*`。写在一个数前面的 `-` 表示取相反数。两个整数用 `/` 相除得到浮点数。`//` 表示商向下取整，`%` 得到与该商对应的余数，`**` 表示乘方。整数和浮点数混合做加法时，结果为浮点数。

```python
print("除法、向下取整和余数", 7 / 2, 7 // 2, 7 % 2)
print("负数的商和余数", -7 // 2, -7 % 2)
print("乘方、混合加法", 2 ** 3, 2 + 1.5)
print("两种分组", 2 + 3 * 4, (2 + 3) * 4)
```

`-7 // 2` 的结果是 -4，因为 -3.5 向下取整是 -4。最后一行得到 14 和 20。常用算术中，乘方优先于乘除，乘除和取余优先于加减。可以用括号改变分组，或把业务规则写得更清楚。连续乘方从右结合，`2 ** 3 ** 2` 相当于 `2 ** (3 ** 2)`。

### 值的比较与逻辑判断

比较人数是否超过容量，可以写 `registered <= capacity`。还可以写链式比较 `0 <= registered <= capacity`，同时检查人数的下限和上限。整型和浮点型可以按数值比较，文字 `"28"` 与整数 `28` 用 `==` 比较则得到 `False`。要判断文字中的数字是否超过容量，应先把它转换成人数。

可以用 `bool()` 查看一个对象在条件中的真假。数值零、空字符串和 `None` 都视为假。字符串 `"0"` 含有一个字符，所以视为真。`not` 将真假取反。`and` 先看左边，左边为假时直接返回左边的对象。`or` 也先看左边，左边为真时直接返回左边的对象。需要继续求值时，两者返回右边的对象。这样的求值方式叫短路。

```python
registered = 28
capacity = 30
booking = True

count_ok = 0 <= registered <= capacity
can_register = booking is True and 0 <= registered < capacity
print("人数有效", count_ok)
print("可以报名", can_register)

confirmed_price = None
price_ready = confirmed_price is not None and confirmed_price > 0
print("已有有效票价", price_ready)
```

把人数改成 30，人数仍然有效，但已经没有空位。最后一条判断中，票价是 `None`，左侧条件为假，Python 便跳过右侧的大小比较。在混合表达式中，比较、标识和成员判断先于逻辑运算，逻辑运算按 `not`、`and`、`or` 的优先级分组。[Python 表达式与运算优先级](https://docs.python.org/3.12/reference/expressions.html#operator-precedence)

### 字符串操作与类型转换

同一个符号会随对象类型表达不同的操作。例如，两个整数用 `+` 相加，两个字符串用 `+` 拼接。字符串乘以整数会重复文字。可以用 `in` 判断一段文字是否出现，用方括号取字符或切片。位置从 0 数起，切片右端的位置不包含在结果中。

表单送来的 `" 28 "` 是文字。用 `strip()` 清理首尾空白后，可以用 `int()` 把它转换为整数。也可以用 `float()` 将小数文字转换为浮点数，用 `str()` 把数字转换为供显示的文字。

```python
raw_count = " 28 "
cleaned = raw_count.strip()
registered = int(cleaned)
activity = "博物馆参观"

print("拼接文字", cleaned + "1")
print("计算人数", registered + 1)
print("取前三个字符", activity[:3])
print("包含参观", "参观" in activity)
```

前两行分别得到 281 和 29。把 `"二十八"` 交给 `int()` 会得到 `ValueError`，表示这段文字无法按所需格式转换。把整数和字符串直接用 `+` 混在一起会得到 `TypeError`。遇到表单数据时，先确定目标类型，再转换并检查值的范围。第 7 章会介绍怎样应对这些错误。

## 1.6 将结果输出给读者

`print()` 会把传给它的对象转换成文本，默认写入标准输出。在本网站，结果显示在代码框下方。多个对象默认用空格分隔，每次输出默认以换行结束。用 `sep` 可以选择对象之间的分隔文字，用 `end` 可以指定末尾写入什么。

```python
activity = "博物馆参观"
remaining = 2

print(activity, remaining, sep="：")
print("剩余名额", end="：")
print(remaining)

message = f"{activity}还剩 {remaining} 个名额。"
print(message)
```

当输出要按一句话组织时，可以先用格式化字符串生成文字，再交给 `print()`。引号前的 `f` 表示花括号里的表达式需要求值。还可以在花括号中指定显示格式。比如 `f"{2.5:.2f}"` 会显示成 `"2.50"`，`f"{5:02d}"` 会把整数 5 显示成 `"05"`。格式化得到的是一个字符串，计算仍然可以使用原来的数值对象。[Python 内置函数](https://docs.python.org/3.12/library/functions.html#print)

## 1.7 完成一条报名提示

现在把前面的知识用在同一项任务上。给活动名称、容量、已报名人数和每人票价绑定名字，分别计算剩余名额与已报名者的总费用，最后生成一句可以直接发布的提示。这里使用已核对的数据，约定人数在零到容量之间，票价以非负整数分给出。

```python
activity = "博物馆参观"
capacity = 30
registered = 28
ticket_cents = 1250

remaining = capacity - registered
total_cents = registered * ticket_cents
yuan = total_cents // 100
cents = total_cents % 100

amount = f"{yuan}.{cents:02d}"
message = f"{activity}：剩余 {remaining} 个名额，门票合计 {amount} 元。"
print(message)
```

28 人的费用是 35000 分。用 `// 100` 得到 350 元，用 `% 100` 得到剩余 0 分，再把分补成两位。最后输出「博物馆参观：剩余 2 个名额，门票合计 350.00 元。」

如果门票尚未报价，可以先约定「按每人多少分计费」，用暂定价格验证计算和提示。正式报价到来后，再核对计价方式和单位，填入实际票价并重新运行。
