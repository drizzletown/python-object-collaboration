# 第三视角 函数与协作封装
> 把资格判断、单次登记和批量处理组织为可分别调用的能力。

## 4.1 同一套报名规则要用在几个地方

第 3 章用一个循环处理一批请求。现在组织者还希望受理临时到达的单条请求，并且能在不改动名单的情况下回答“这个学号现在能报名吗”。这三个入口需要遵守同一套报名规则。

| 任务 | 接收的信息 | 交出的结果 |
| --- | --- | --- |
| 检查报名资格 | 整理过的学号、现有名单、容量 | 一条回执，名单保持原样 |
| 登记单条请求 | 原始学号、现有名单、容量 | 整理后的学号和回执，通过时更新名单 |
| 处理整批请求 | 按到达顺序排列的学号、现有名单、容量 | 按相同顺序排列的回执记录 |

普通函数可以从第三视角接收这些对象，安排它们协作并交出结果。调用者只需要知道它接收什么、返回什么、会改变什么。

## 4.2 从定义到调用

### 形参、实参与返回值

`def` 创建函数对象，并把函数名绑定到它。调用时，实参是调用者提供的对象，形参是函数内接收这些对象的名字。函数执行到 `return` 时结束这次调用，把指定对象交给调用者。写空的 `return` 或执行到末尾，结果都是 `None`。

```python
def split_seconds(total):
    minutes = total // 60
    seconds = total % 60
    return minutes, seconds


result = split_seconds(125)
minutes, seconds = result
print(result)
print(f"{minutes} 分 {seconds} 秒")
```

`return minutes, seconds` 返回一个二元组。调用者可以把整个结果绑定到一个名字，也可以解包。这里由调用者负责显示，函数可以继续为其他调用者计算时长。

读一次调用，可以顺着对象的去向跟踪。先计算实参 `125`，把它绑定给局部名字 `total`。函数体建立 `minutes` 和 `seconds`，最后交出元组。函数调用结束后，调用处通过 `result` 继续引用这个元组。下次调用会有自己的局部名字和计算结果。

### 参数怎样接收实参

| 形式 | 例子 | 调用方式 |
| --- | --- | --- |
| 位置或关键字参数 | `value` | 按位置提供，或写成 `value=20` |
| 带默认值的参数 | `unit="米"` | 省略时使用定义时的默认值 |
| 仅关键字参数 | `*, digits=1` | 提供时写成 `digits=2` |
| 仅位置参数 | `value, /` | 调用时通过位置提供 `value` |
| 接收额外位置实参 | `*values` | 额外的位置实参收成元组 |
| 接收额外关键字实参 | `**options` | 额外的关键字实参收成字典 |

单独的 `*` 标记后面的形参只接收关键字，`/` 标记前面的形参只接收位置实参。编写普通函数时，可以先用固定参数表达契约，再根据调用场景决定是否需要其余形式。

```python
def format_measurement(value, unit="米", *, digits=1):
    rounded = f"{value:.{digits}f}"
    return f"{rounded} {unit}"


print(format_measurement(2.345))
print(format_measurement(2.345, "千米", digits=2))
print(format_measurement(value=2.345, unit="秒", digits=0))
```

### 按接口核对实际调用

| 调用形式 | 怎样绑定或为什么失败 |
| --- | --- |
| `format_measurement(2.345)` | `value` 取第一个实参，其余使用默认值 |
| `format_measurement(2.345, digits=2)` | `digits` 明确按关键字提供 |
| `format_measurement(2.345, "米", 2)` | 给了第三个位置实参，`digits` 只接受关键字 |
| `format_measurement(2.345, value=3)` | `value` 已通过位置提供，再用关键字提供会重复 |
| `format_measurement()` | 缺少必需的 `value` |

后三种调用在进入函数体前就会报告 `TypeError`。参数规则能帮助设计接口。例如要求调用者写 `capacity=2`，读调用代码时就能看出 2 表示容量。

## 4.3 默认值、收集参数与展开实参

参数默认值在执行函数定义时求值。如果用空列表作为默认值，每次省略该参数时会得到同一个列表。若每次调用都应获得新列表，可以让参数默认值为 `None`，在函数内部用 `is None` 检查并创建列表。[Python 官方教程的函数定义与参数](https://docs.python.org/3.12/tutorial/controlflow.html#defining-functions)

### 用两个调用观察默认对象

```python
def collect_shared(value, values=[]):
    values.append(value)
    return values


def collect_separately(value, values=None):
    if values is None:
        values = []
    values.append(value)
    return values


first = collect_shared("甲")
second = collect_shared("乙")
print("共享默认列表", first, second, first is second)

left = collect_separately("甲")
right = collect_separately("乙")
print("分别创建列表", left, right, left is right)
```

第一组调用中，两次都使用定义时创建的那份默认列表。第一次保存下来的 `first` 在第二次调用后也会看到“乙”。第二组调用在每次省略参数时新建列表。显式传入一个列表时，仍会在那一份列表中追加内容，这个行为应当写进函数的约定。

### 用星号把多个对象收集起来或展开

在定义中，`*counts` 收集多余的位置实参，`**details` 收集多余的关键字实参。在调用中，`*values` 把一组数据展开成位置实参，`**options` 则用字典中的键名提供关键字实参。可以用同一组值对比直接传入与展开传入的效果。

```python
def format_counts(title, /, *counts, unit="项", **details):
    number = sum(counts)
    source = details.get("source", "未标明来源")
    return f"{title}共 {number} {unit}（{source}）"


values = (3, 4)
options = {"unit": "份", "source": "登记表"}
print(format_counts("资料", 3, 4, unit="份", source="登记表"))
print(format_counts("资料", *values, **options))
```

两次调用交出的内容相同。`unit` 在星号参数后，需要按关键字指定。`details` 里只收集未被其他形参接收的关键字，例如 `source`。固定参数已经能说明契约时，调用代码可以保持简洁。有不同长度的数据或需要转交一组参数时，再使用收集和展开。

## 4.4 局部名字、外层名字与共享对象

每次调用都会建立自己的局部名字。函数体中对名字赋值，通常建立或改变本次调用的局部绑定。读一个名字时，Python 会根据作用域查找，可能找到局部、外层函数、模块或内置名字。显式传入数据更容易看清函数依赖哪些对象。

### 名字在哪里可以找到

| 位置 | 例子 | 在哪里可访问 |
| --- | --- | --- |
| 局部 | 函数参数、函数内部赋值的名字 | 当前这次调用中 |
| 外层函数 | 包含当前函数的那次调用中的名字 | 内部函数可读取它 |
| 模块 | 在文件顶层绑定的名字 | 同一模块的函数可以访问 |
| 内置 | `len`、`print` | 没有被更近的同名绑定覆盖时可访问 |

在函数体里给名字赋值，通常使它成为局部名字。因此，同一个函数中若先读某个尚未赋值的局部名字，之后才给它赋值，可能看到 `UnboundLocalError`。下例用不同的参数显式给计算提供所需数据。

```python
tax_rate = 0.05

def total_with_tax(price, rate):
    extra = price * rate
    return price + extra


print("采用模块提供的费率", total_with_tax(100, tax_rate))
print("采用指定费率", total_with_tax(100, 0.08))
print("模块中的费率", tax_rate)
```

`global` 可以指定某个名字使用模块的绑定，`nonlocal` 可以指定使用最近的外层函数绑定。先从参数和返回值表达数据怎样流入流出，阅读函数时就能从调用处看出它依赖哪些值。后面会用闭包示例展示 `nonlocal` 的一种用途。[Python 官方文档的作用域规则](https://docs.python.org/3.12/reference/executionmodel.html#resolution-of-names)

### 改名字与改对象的影响范围

形参与实参可以引用同一个对象。修改可变对象的内容，调用者可以看到变化。把形参改绑到新对象，外面的名字仍引用原来的对象。

```python
def add_sample(values, reading):
    values.append(reading)


def start_over(values):
    values = []
    return values


samples = [12]
add_sample(samples, 16)
empty = start_over(samples)
print(samples)
print(empty)
```

`add_sample` 返回 `None` 并原地追加读数。`start_over` 返回一个新列表，`samples` 仍引用含有两项的旧列表。为函数写契约时，可以用一句话写明它会不会修改参数指向的对象。

## 4.5 用接口说明结果与影响

同一个功能可以用打印提示或返回数据来实现，两种做法给后续步骤的能力不同。调用者需要继续计算时，应取得可使用的值。显示用的函数可以单独接收结果，决定显示成什么格式。

```python
def calculate_area(width, height):
    return width * height


def display_area(area):
    print(f"面积 {area} 平方米")


area = calculate_area(3, 4)
print("两块相同区域的总面积", area * 2)
printed = display_area(area)
print("显示函数的返回值", printed)
```

`calculate_area()` 交出数值，`display_area()` 输出文字并返回 `None`。把两项能力分开后，其他地方可以只使用面积，也可以换一种方式显示面积。

一个可检验的函数契约可以写在文档字符串中，说明接收什么、满足哪些条件、交出什么，以及会不会改变外部对象。还应根据任务说明失败时交出什么。比如一项计算只接受正的宽和高，调用者需要知道是否应先验证取值。对于修改列表的函数，最好明确修改哪一份列表以及成功和失败时有何差别。

## 4.6 函数也能作为参数或结果

一个函数可以交给另一个函数调用。传递 `abs` 是交出函数对象，写 `abs(-4)` 则立即调用并取得结果。接受函数作为参数，可以让调用者选择规则，组织步骤的函数只负责在合适时机使用它。

```python
def convert_all(values, convert):
    return [convert(value) for value in values]


def make_multiplier(factor):
    def multiply(value):
        return value * factor

    return multiply


readings = [-4, 2]
print(convert_all(readings, abs))
double = make_multiplier(2)
print(convert_all(readings, double))
print(sorted(["铅笔", "三角板", "尺"], key=lambda text: len(text)))
```

`make_multiplier` 返回的内部函数仍能访问创建它时外层调用中的 `factor` 绑定。这种函数称为闭包。分别调用 `make_multiplier(2)` 和 `make_multiplier(3)` 会得到使用不同倍数的函数。`lambda` 用一个表达式创建小函数，示例把它交给 `sorted`，以文字长度作为排序依据。

### 闭包也可以保存一份会变化的状态

内部函数读取外层名字时使用的是绑定。若要重新绑定外层函数里的名字，可以声明 `nonlocal`。下面每次调用 `make_counter` 都创建自己的起始值，返回的函数以后还能读取并增加这份计数。

```python
def make_counter(start):
    value = start

    def count():
        nonlocal value
        value += 1
        return value

    return count


count_a = make_counter(0)
count_b = make_counter(10)
print(count_a(), count_a())
print(count_b(), count_a())
```

输出依次展示 A 的 1、2，B 的 11，以及 A 的 3。两个函数共享同一种行为，各自保留创建时的一份状态。若只需要配置一个固定倍数，可以像前面的 `make_multiplier` 那样读取外层值。

## 4.7 用递归函数处理嵌套结构

递归函数直接或间接调用自己。先确定可以直接回答的情形，再确保每次调用解决更小的问题。例如，统计一份零件清单时，遇到名称就计一个，遇到分组就分别统计组内各项。

```python
def count_parts(group):
    if isinstance(group, str):
        return 1

    total = 0
    for item in group:
        total += count_parts(item)
    return total


parts = ["电池", ["螺钉", "垫片"], "外壳"]
print(count_parts(parts))
```

`isinstance(group, str)` 判断对象是否为字符串。对本例的有限嵌套列表，每次递归都进入更小的分组或具体零件。导论中的递归使用假设三部曲是一种设计方法，每次兑现遇到新难题就形成子任务。子任务可以用函数、对象或现成的库来完成。

### 跟着调用结果逐层返回

| 调用拿到的对象 | 做什么 | 交回结果 |
| --- | --- | --- |
| `"电池"` | 直接计一项 | 1 |
| `["螺钉", "垫片"]` | 分别求两项的数量，再相加 | 2 |
| `"外壳"` | 直接计一项 | 1 |
| 最外层清单 | 使用以上三项结果 | 4 |

递归调用返回后，上一层继续执行自己的累加语句。清单为空时，循环执行零次，返回初始值 0。这个任务约定清单有限，且子组的引用最终会到达具体零件或空组。设计递归时，可以先为最小问题写出结果，再检查每个子问题是否比原问题更接近停止条件。

## 4.8 用生成器按需产生结果

含有 `yield` 的函数被调用时会返回生成器。每次取下一项才推进函数体，执行到 `yield` 就交出一个值并暂停。调用者可以先消费一部分结果，其余结果留到需要时再产生。

```python
def nonempty_lines(lines):
    for line in lines:
        text = line.strip()
        if text:
            yield text


lines = nonempty_lines(["  第一行  ", " ", "第二行"])
print(next(lines))
print(list(lines))
print(list(lines))
```

第一次 `next` 得到“第一行”。第一次转为列表会取得余下的“第二行”，第二次转为列表时生成器已耗尽。一次性需要全部结果时，返回列表便于重复访问。按需处理很多数据时，可用生成器减少一次性保存的结果。[Python 官方教程的生成器](https://docs.python.org/3.12/tutorial/classes.html#generators)

### 观察暂停的位置和剩余结果

```python
def convert_readings(values):
    for value in values:
        print("正在转换", value)
        yield value * 100


converted = convert_readings([1, 2, 3])
print("已取得生成器")
print("先要一项", next(converted))
print("继续取得剩余项", list(converted))
```

“已取得生成器”先显示，说明调用生成器函数时还没有开始转换。`next()` 只运行到第一次 `yield`。之后 `list()` 继续读取，直到生成器结束。将结果保存为列表会一次收集所有剩余项。如果只需要前几项，可以逐项请求并在达到目的时停止。

## 4.9 回到案例 封装三个报名任务

先约定资格检查会给出一条回执。单次登记拿到回执后，据此决定是否写入名单，并交出整理后的学号和回执。批量处理对每条请求调用单次登记，把收到的结果累积起来。显示代码接收整批记录并负责输出。

可以先按这个约定写出上层的批量处理，再兑现每次登记所需的判断。用步骤描述函数之间怎样交接结果。

```text
任务：批量登记并交回逐条结果
    1. 输入：原始请求、现有名单、活动容量。
    2. 处理：逐条调用单次登记。
        2.1 单次登记整理学号，调用资格检查，取得回执。
        2.2 回执为“通过”时，单次登记更新名单。
        2.3 批量处理取得整理后的学号和回执，将它们加入结果。
    3. 输出：交出整批结果，由调用处负责呈现。
```

```python
def check_eligibility(student_id, roster, *, capacity):
    """接收已去掉首尾空白的学号，返回回执。"""
    if not student_id:
        return "空学号"
    if student_id in roster:
        return "重复"
    if len(roster) >= capacity:
        return "满员"
    return "通过"


def register(raw_id, roster, *, capacity):
    student_id = raw_id.strip()
    status = check_eligibility(student_id, roster, capacity=capacity)
    if status == "通过":
        roster[student_id] = "已报名"
    return student_id, status


def process(requests, roster, *, capacity=2):
    receipts = []
    for raw_id in requests:
        receipt = register(raw_id, roster, capacity=capacity)
        receipts.append(receipt)
    return receipts


roster = {}
print("检查资格", check_eligibility("S01", roster, capacity=2))
print("检查后的名单", list(roster))
print("单次登记", register(" S01 ", roster, capacity=2))
print("批量回执")
for student_id, status in process([" ", " S02 ", "S03", "S01"], roster):
    print(student_id or "（空白）", status)
print("最终名单", list(roster))
```

前两行输出表明，资格检查返回“通过”时名单仍为空。单次登记后，批量处理的四条回执依次是“空学号、通过、满员、重复”。最终名单为 `["S01", "S02"]`。三个入口都沿用同一处资格规则。

### 单独验证各项契约

| 验证目标 | 初始状态和输入 | 要核对的结果 |
| --- | --- | --- |
| 资格检查的影响 | 空名单，查看 S01 是否可报名 | 回执为通过，名单仍为空 |
| 登记的输入和结果 | 原始学号带有首尾空格 | 返回整理后的学号，通过时按该学号写入 |
| 批量的次序 | 先满员，再收到旧学号 | 回执顺序与输入相同，重复优先于满员 |
| 批量为空 | 给出已有名单和空请求列表 | 交出空列表，保留已有名单 |

用不同的名单调用同一组函数，就能复用这套规则。每次登记都要一起传入当前名单和容量。下章会把两项状态交给同一个活动对象维护。[第 5 章 第一视角 自定义对象与类](05.md)
