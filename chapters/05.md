# 第一视角 自定义对象与类
> 用活动对象集中保存容量和名单，让它维护自己的报名规则。

## 5.1 把相关状态和行为交给同一个对象
普通函数可以接受一份名单和一个容量。多个活动并存时，如果把甲活动的名单和乙活动的容量传给同一次登记，程序仍可能运行，但结果会错。类允许把相关状态集中在实例中。类定义描述实例如何初始化以及提供什么方法，每次创建实例时都应给它一份独立名单。
调用 museum.register("S01") 时，Python 会把 museum 作为方法的第一个参数传入。按惯例命名为 self。对象通过 self 读取和更新自己的属性。以下代码用活动对象承担检查学号和维护容量的职责，外部负责选择活动并展示回执。

```python
class Activity:
    def __init__(self, title, capacity):
        if type(capacity) is not int or capacity < 0:
            raise ValueError("容量须为非负整数")
        self.title = title
        self._capacity = capacity
        self._roster = {}

    @property
    def capacity(self):
        return self._capacity

    def register(self, raw_id):
        student_id = raw_id.strip()
        if not student_id:
            return "空学号"
        if student_id in self._roster:
            return "重复"
        if len(self) >= self.capacity:
            return "满员"
        self._roster[student_id] = "已报名"
        return "通过"

    def student_ids(self):
        return tuple(self._roster)

    def __len__(self):
        return len(self._roster)

museum = Activity("博物馆", 2)
lab = Activity("实验室", 1)
print(museum.register("S01"))
print(lab.register("S01"))
print(museum.student_ids(), len(museum), museum.capacity)
```

__init__ 在实例创建之后初始化属性。_roster 前面的下划线提示外部代码将它视作内部实现。student_ids 返回由字符串构成的元组快照，调用方可读取学号，无法通过这个快照改变名单。property 提供可读取的 capacity；类的内部仍可以访问 _capacity。raise 会在容量不合法时报告错误，第 7 章介绍如何接收错误。

## 5.2 让实例参加通用操作
len(museum) 使用 __len__ 返回名单长度。形如 __len__ 的特殊方法可以让自定义对象参与 Python 的通用操作。还可以定义 __repr__，给调试时查看的对象提供简洁表示。定义特殊方法时要遵守它的含义，例如 __len__ 返回非负整数。
在条件表达式中，定义了 __len__ 且长度为 0 的活动对象会被当成假值。要判断活动是否缺失，用 activity is None。用 if activity 同时检查了对象的真值，可能把合法的空活动遗漏。

## 5.3 同时保留两种视角
Activity.register 决定这个活动接受谁。一个批量登记函数可以接收 activity 和请求列表，逐一调用 register，把回执交给显示端。类维护状态和不变式，函数描述跨对象的步骤。创建类时先问“这个实例需要长期维护哪些状态”，再决定把哪些行为交给它。

## 练习
为 Activity 添加 remaining 方法，返回剩余名额。分别测试空活动、满员活动以及重复报名。
:::answer
在方法内返回 self.capacity - len(self)。新建容量为 1 的活动，初始结果为 1；成功登记后为 0；再次登记同一学号后仍为 0。
