# 第一视角 自定义对象与类
> 让每个活动对象维护自己的容量和名单，通过方法完成登记、取消与查询。

## 5.1 两场活动各自管理什么

第 4 章把登记写成函数，调用时需要把名单和容量一起传入。现在同时开放博物馆参观和实验室体验，两场活动名额不同。如果调用时把甲活动的名单和乙活动的容量配到一起，程序就可能给出错误的回执。

- 博物馆容量为 2，实验室容量为 1。两场活动都从空名单开始。
- 同一学号可以分别参加两场活动。重复和满员以收到请求的活动为准。
- 取消一场活动的报名只影响这场活动。组织者可以查询名单和剩余名额。

需要一个角色把相关数据和操作集中在一起。调用者选定活动，然后请它自己处理登记或取消。Python 用类描述这种拥有专属状态和职责的对象。

可以先写出两份状态的预期变化。用同一个学号分别报名时，两场活动都能各自接受一次。实验室取消这个学号后，它应释放一个名额，博物馆仍保留原来的报名。后面会用这一组操作检查每个实例是否真的拥有自己的状态。

## 5.2 从类到实例

类描述一种对象可以保存什么、能做什么。执行 `class` 定义后，类名绑定到一个类对象。调用这个类会创建实例，`__init__` 通常负责设置新实例的初始属性。一个类可以创建多个身份各异的实例。

```python
class StepCounter:
    unit = "步"

    def __init__(self, label):
        self.label = label
        self.total = 0

    def record(self, steps):
        self.total += steps
        return self.total


morning = StepCounter("上午")
evening = StepCounter("傍晚")
print(type(morning).__name__, morning is evening)
print(morning.label, morning.record(120), morning.unit)
print(evening.label, evening.total, evening.unit)
```

`label` 和 `total` 属于各自的实例。`unit` 定义在类体里，两次访问都从类中取得同一个单位。若把一份可变列表写成类属性，各实例通过它追加元素时会改动同一个列表。需要独立保存的可变状态应当在 `__init__` 中为每个实例创建。

### 类对象、实例和初始化的分工

`StepCounter` 是类对象，`morning` 和 `evening` 是通过调用它创建的实例。`type(morning) is StepCounter` 可以核对实际类型。`__init__` 接收刚创建的实例并设置初始属性，它执行完毕后由类调用交出实例。初始化方法本身应正常结束，通常省略 `return`。

构造对象时要决定初始状态应该是什么。调用 `StepCounter("上午")` 只要求提供标签，计数从 0 开始。需要为每个实例维护的计数和列表，都应在每次初始化时建立。可以从预期操作反推初始状态，例如允许空记录就要能在刚创建时给出长度 0。

## 5.3 属性怎样查找与共享

### 区分实例状态和类上的公共信息

普通实例属性可由 `self.name = value` 建立。读取普通属性时，实例上有自己的值就读取它，否则可以从类上找到公共值。下面让一个标签使用特殊单位，再修改类上的公共单位，观察两个实例读取的是哪里。

```python
class Label:
    unit = "厘米"

    def __init__(self, name):
        self.name = name


left = Label("左")
right = Label("右")
right.unit = "毫米"
Label.unit = "米"

print("类的单位", Label.unit)
print(left.name, left.unit)
print(right.name, right.unit)
```

右侧标签已建立自己的 `unit` 属性，所以会继续读到“毫米”。左侧标签使用类上的值。`@property` 等机制还可以约定怎样计算或限制某个属性，稍后会介绍。

### 每个实例应拥有独立的可变状态

若把一个列表设在类上，多个实例可能通过属性找到同一份列表。对其中一个引用做原地追加，会影响其他实例看到的内容。要让每个对象保存自己的操作记录，应在 `__init__` 中分别创建列表。

```python
class SharedNotebook:
    lines = []


class Notebook:
    def __init__(self):
        self.lines = []


a = SharedNotebook()
b = SharedNotebook()
a.lines.append("甲的第一条")
print("共享的记录", b.lines, a.lines is b.lines)

first = Notebook()
second = Notebook()
first.lines.append("甲的第一条")
print("独立的记录", second.lines, first.lines is second.lines)
```

前一组中的两个属性引用同一个列表，后一组由两次初始化各建一份。给实例属性重新赋值与修改某个已有列表，是第 2 章讲过的两种操作。

## 5.4 方法怎样得到要操作的对象

读取 `morning.record` 会得到绑定到 `morning` 的方法。调用 `morning.record(120)` 时，Python 把 `morning` 传给方法的第一个形参，惯例写为 `self`。方法内通过 `self.total` 访问当前实例的总步数。

| 写法 | 访问的内容 | 示例 |
| --- | --- | --- |
| `obj.name` | 对象公开的一个属性 | 读取计数器的标签 |
| `obj.method` | 绑定到这个实例的方法 | 把方法作为可调用对象传递 |
| `obj.method(value)` | 请这个实例执行一项操作 | 将新增步数累加到总步数 |
| `self.name` | 方法内访问当前实例的属性 | 更新接收调用的计数器 |

普通函数也可以接收实例，调用它的方法并使用结果。当任务需要协调多个角色时，函数可以从第三视角安排先后，实例仍负责各自的行为和状态。[Python 官方教程的类与实例](https://docs.python.org/3.12/tutorial/classes.html#class-objects)

### 可以保存绑定后的方法

`counter.add` 在读取时就与当前计数器绑定。以后调用这个方法，仍会把那个对象作为 `self`。通过类取得普通函数时，可以显式提供实例。这两种调用方式有助于看清方法的参数从哪里来。

```python
class Counter:
    def __init__(self):
        self.total = 0

    def add(self, amount):
        self.total += amount
        return self.total


counter = Counter()
add_to_counter = counter.add
print("调用保存的方法", add_to_counter(2))
print("从类取得函数并提供实例", Counter.add(counter, 3))
print("计数结果", counter.total)
```

第一次调用使总数变为 2，第二次继续加 3。函数定义中的 `self` 在两次调用中都引用同一个对象。读取属性来获得数据，或者读取方法来传递一项能力，由调用处根据任务选择。

### 实例方法、类方法和静态方法

| 方法形式 | 由 Python 自动提供 | 常见职责 |
| --- | --- | --- |
| `def method(self, ...)` | 当前实例 | 读取或修改该实例的状态 |
| `@classmethod` | 当前类，惯例写作 `cls` | 从另一种输入格式构造实例，或使用类级别配置 |
| `@staticmethod` | 没有自动提供的实例或类 | 定义和这个类型相关、只依赖实参的操作 |

```python
class Length:
    def __init__(self, centimeters):
        if not self.is_valid(centimeters):
            raise ValueError("长度须为非负整数厘米")
        self.centimeters = centimeters

    @classmethod
    def from_meters(cls, meters):
        if meters < 0:
            raise ValueError("以米计的长度须为非负值")
        return cls(round(meters * 100))

    @staticmethod
    def is_valid(centimeters):
        return type(centimeters) is int and centimeters >= 0


length = Length.from_meters(1.25)
print("厘米数", length.centimeters)
print("负数是有效长度", Length.is_valid(-2))
```

`from_meters` 先把单位换成厘米，再通过 `cls(...)` 走同一套初始化规则。`is_valid` 只使用传来的值。是否要把这种操作写在类中，可以看它是否属于这个类型的约定。只依赖数据、也常为其他对象使用的计算，可以写成普通函数。

## 5.5 用公开操作维护状态

对象的状态可能有需要始终成立的条件。例如，音量必须处在 0 到 100 之间。可以把直接保存的值视为内部实现，将读值和改值作为公开操作。方法先检查新值是否合规，再执行修改。

```python
class Volume:
    def __init__(self, level):
        self.set_level(level)

    @property
    def level(self):
        return self._level

    def set_level(self, level):
        if type(level) is not int or not 0 <= level <= 100:
            raise ValueError("音量须为 0 到 100 的整数")
        self._level = level


speaker = Volume(30)
speaker.set_level(45)
print(speaker.level)
```

`_level` 的前导下划线按惯例表示供类内部使用。外部通过 `speaker.level` 读取当前值，通过 `speaker.set_level(45)` 请求修改。`@property` 让读取操作采用属性的写法。这个属性只定义了读取方法，常规的 `speaker.level = 45` 赋值不会生效，并会报告属性错误。非法音量通过 `raise` 报告，稍后的第 7 章讲解怎样处理这种错误。

如果对象内部保存的是可变容器，查询方法还要考虑调用者能否通过返回值改动原状态。可以按需求返回统计值、复制结果或由不可变值组成的元组快照。快照记录取得它时的数据。

### 属性可以计算，也可以检查赋值

一个属性可以由已有状态计算出来。例如摄氏温度和华氏温度之间可以转换。只保存摄氏值，读取华氏值时再计算，可以避免同时维护两个容易失去一致性的数值。若希望支持赋值写法，可以用 `@name.setter` 把赋值交给指定的方法。

```python
from math import isfinite


class Temperature:
    def __init__(self, celsius):
        self.celsius = celsius

    @property
    def celsius(self):
        return self._celsius

    @celsius.setter
    def celsius(self, value):
        if not isfinite(value) or value < -273.15:
            raise ValueError("摄氏温度须为有限值且不低于绝对零度")
        self._celsius = value

    @property
    def fahrenheit(self):
        return self._celsius * 9 / 5 + 32


temperature = Temperature(0)
print("摄氏与华氏", temperature.celsius, temperature.fahrenheit)
temperature.celsius = 20
print("更新后", temperature.celsius, temperature.fahrenheit)
```

初始化和外部赋值都通过 `celsius` 的赋值方法，检查结束后才更新底层属性。`fahrenheit` 只提供读取，用同一份状态计算。对需要有明确动作含义的操作，例如“充值”“取消”或“重置”，用有名字的方法通常更容易说明影响。

### 容器怎样进入和离开对象

对象接受外部列表时，要决定保留共享引用还是独立保存数据。查询时也要决定交出内部列表、外层副本，还是由不可变元素组成的快照。下面的路线只需要记住创建时的站点顺序。

```python
class Route:
    def __init__(self, stops):
        self._stops = tuple(stops)

    def stops(self):
        return self._stops


planned = ["起点", "东站"]
route = Route(planned)
planned.append("西站")
print("原计划列表", planned)
print("路线对象的站点", route.stops())
```

路线使用元组保存站点顺序，站名本身是字符串。传入列表随后增加站点，路线仍保留创建时的两个站名。若成员本身是可变对象，需要根据第 2 章的复制规则判断内层状态是否共享。

## 5.6 让实例参与 Python 的通用操作

`__init__` 是一种特殊方法。类似的双下划线方法也可为 `len(obj)`、`repr(obj)` 等通用操作定义行为。方法需要遵守相应约定，例如 `__len__` 返回非负整数，`__repr__` 返回便于查看的字符串。

| 公开操作 | 对应的特殊方法 | 约定 |
| --- | --- | --- |
| `len(obj)` | `__len__` | 交出非负整数 |
| `bool(obj)` | `__bool__`，也可依据 `__len__` | 表示在真假判断中的意义 |
| `repr(obj)` | `__repr__` | 交出用于查看对象的字符串 |
| `str(obj)`、`print(obj)` | `__str__` | 交出面向读者的显示文字 |
| `item in obj` | 可通过 `__contains__` 实现 | 判断成员关系 |
| `left == right` | 可通过 `__eq__` 实现 | 按领域约定比较值 |

```python
class WordList:
    def __init__(self, words):
        self._words = list(words)

    def __len__(self):
        return len(self._words)

    def __repr__(self):
        return f"WordList({self._words!r})"

    def __str__(self):
        return "、".join(self._words)

    def __contains__(self, word):
        return word in self._words


words = WordList(["蓝", "绿"])
print("长度", len(words))
print("查看对象", repr(words))
print("给读者看的文字", words)
print("包含绿", "绿" in words)
print("空对象的真值", bool(WordList([])))
```

本例没有定义 `__bool__`，因此 Python 用 `__len__` 的结果判断真值。长度为零的实例在条件中为假。如果要判断某个查找结果是否缺失，使用 `result is None` 可以明确检查缺失值。

### 什么时候适合按值比较

一对坐标可按横、纵坐标比较。同一坐标的两个对象可以有相同的值和不同的标识。对两个活动对象，则可能需要按活动编号或对象身份区分，标题相同也可能是两场不同的活动。

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __eq__(self, other):
        if not isinstance(other, Point):
            return NotImplemented
        return (self.x, self.y) == (other.x, other.y)


left = Point(3, 4)
right = Point(3, 4)
print("坐标相等", left == right)
print("是同一对象", left is right)
```

`NotImplemented` 表示此方法没有定义与该类型的比较，由 Python 继续处理这次运算。定义特殊方法时，可以先写出它对该对象应表达的含义。若对象没有自然的长度、顺序或相等规则，可以只提供任务实际需要的方法。[Python 官方文档的特殊方法](https://docs.python.org/3.12/reference/datamodel.html#special-method-names)

## 5.7 回到案例 让活动维护自己的报名

`Activity` 把容量和名单放在同一个实例里。登记依次检查空学号、重复和满员。取消只从当前名单移除对应学号，成功后释放一个名额。查询名单时交出由学号字符串组成的元组，外部可以读取而不会改动名单。

| 活动对外提供的操作 | 结果 | 对状态的影响 |
| --- | --- | --- |
| `register(raw_id)` | 通过、空学号、重复或满员 | 通过时新增一人 |
| `cancel(raw_id)` | 已取消、空学号或未报名 | 已取消时移除一人 |
| `student_ids()` | 按登记次序保存学号的元组 | 查询 |
| `remaining()`、`len(activity)` | 剩余名额或人数 | 查询 |

名额和名单共同决定两条不变式，人数不能超过容量，学号在同一活动中只出现一次。构造时创建空名单。登记先检查，再写入。取消从当前实例的名单移除指定记录，也就能在下一次登记时重新利用这个名额。

```python
class Activity:
    def __init__(self, title, capacity):
        if type(capacity) is not int or capacity < 0:
            raise ValueError("容量须为非负整数")
        self.title = title
        self._capacity = capacity
        self._roster = {}

    @property
    def capacity(self):
        return self._capacity

    def register(self, raw_id):
        student_id = raw_id.strip()
        if not student_id:
            return "空学号"
        if student_id in self._roster:
            return "重复"
        if len(self) >= self.capacity:
            return "满员"
        self._roster[student_id] = "已报名"
        return "通过"

    def cancel(self, raw_id):
        student_id = raw_id.strip()
        if not student_id:
            return "空学号"
        if student_id not in self._roster:
            return "未报名"
        del self._roster[student_id]
        return "已取消"

    def student_ids(self):
        return tuple(self._roster)

    def remaining(self):
        return self.capacity - len(self)

    def __len__(self):
        return len(self._roster)


def show_status(activity):
    print(activity.title, activity.student_ids(), "剩余", activity.remaining())


museum = Activity("博物馆", 2)
lab = Activity("实验室", 1)
print("同一学号分别报名", museum.register("S01"), lab.register("S01"))
print("实验室再收请求", lab.register("S01"), lab.register("S02"))
print("取消实验室报名", lab.cancel("S01"))
print("实验室重新接收 S02", lab.register("S02"))
show_status(museum)
show_status(lab)
```

最后博物馆的名单为 `("S01",)`，还剩一个名额。实验室的名单为 `("S02",)`，剩余名额为零。两次 `show_status` 调用都使用活动提供的公开操作，同样的函数可以查看任何一个活动的状态。

### 对比对象内部和外部的职责

| 执行后 | 博物馆名单 | 实验室名单 |
| --- | --- | --- |
| S01 分别报名 | S01 | S01 |
| 实验室重复登记 S01，再收 S02 | S01 | S01 |
| 实验室取消 S01 | S01 | 空 |
| 实验室再收 S02 | S01 | S02 |

`register` 和 `cancel` 使用 `self` 维护各自的状态，体现第一视角。`show_status` 从第三视角使用对象公开的查询能力。它既能读取博物馆的状态，也能读取实验室的状态。后面如果收到的只有活动编号，就要在调用之前由另一个角色把编号对应到对象。[第 6 章 多对象协作与程序组织](06.md)
