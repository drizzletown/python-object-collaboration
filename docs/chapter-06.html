6.1 收到活动编号后，谁负责找到对象

第 5 章可以直接拿着 museum 或 lab 对象办理报名。真正收到的请求通常只有活动编号和学号，例如 ("museum", "S01")。程序要先把编号对应到活动，再请该活动决定是否接受请求。

  • 输入是若干已开放的活动，以及包含活动编号和学号的报名请求。
  • 找到活动时，沿用活动自己的空学号、重复和容量规则。找不到活动时，返回“活动不存在”。
  • 输出是每次请求的回执。查询未知编号后，已有活动的名单应保持原样。

从接收请求到给出回执，中间有查找、更新状态和呈现结果几项工作。把这些工作分给不同角色，才能独立调整查询方式或展示方式。

这项任务还有两种不同的变化。活动规则可能增加一个资格条件，查找方式则可能从字典换成别的来源。先分清哪些结果需要跨过职责边界，再决定由谁持有数据、由谁组织调用。

6.2 组合对象与约定接口

当一个对象持有另一个对象并通过其公开操作完成一部分工作，就形成了对象组合。例如，一个补货检查器接收库存查询对象。它只需知道查询操作的名字、需要提供的参数、会交出的结果。创建检查器时把所需对象传进去，就可以让调用者选择它使用哪一份库存数据。

quantity 的接口约定是接收货品编号，返回非负整数，找不到时返回 None。检查器拿到 0 时会继续判断是否补货，拿到 None 时直接返回“无此货品”。使用接口时，除了记住方法名，还要明确如何解释返回值、调用是否改变状态、什么情况需要报告失败。

6.3 用类型标注和记录对象传递信息


读懂接口上的类型标注


标注表达的约定使用位置
code: str参数应为字符串根据编号查找
dict[str, int]字典的键是字符串，值是整数记录各项库存
int | None结果是整数或缺失值查找可能没有结果
-> str函数交出字符串生成一条检查结论
-> None函数没有需要调用者使用的返回值更新状态或发送输出


类型标注帮助读代码的人、编辑器和静态检查工具理解接口。普通调用不会因为写了标注就自动检查或转换实参。诸如整数必须非负、字符串必须非空，仍要通过校验和文档表达。Python 官方文档的类型标注


标注描述类型，行为还要另外约定


list[str] 表示列表中的每项应为字符串。tuple[str, ...] 表示长度可变的字符串元组。A | B 表示对象可以属于两种类型之一，常用于表示找到对象或交回 None。如果还要说明状态只能取几个指定文字，可以在文档里列出允许的值，也可以用 typing.Literal 表达给类型检查工具。

6.5 用包和依赖方向组织程序


按职责划分模块


相关模块可以组成包。普通包包含 __init__.py，其中可以安排包的初始化或对外入口。包内可以用 from .readings import Measurement 导入同包的模块，也可以使用从包名开始的绝对导入。示意目录中的 report.py 需要了解记录的格式，记录类则可以独立存在。


weather/
    __init__.py    普通包的初始化文件
    readings.py    定义 Measurement
    report.py      导入 Measurement，组织报告
    __main__.py    构造数据并调用报告功能


从包含 weather 的目录启动包时，python -m weather 会执行 weather/__main__.py。当两个模块出现相互导入时，可以沿着职责检查哪一方真正需要另一方的能力，或把共同使用的记录类型放在双方都能导入的位置。Python 官方教程的模块与包


从实际调用推导模块之间的关系


给出一个目录结构后，还要解释每个文件需要谁。下面的报告程序从入口取得示例数据，由报告模块组织输出。记录模块只负责表达数据，可以独立导入。


weather/__main__.py
    导入 readings 里的 Measurement。
    导入 report 里的 summarize。
    构造读数，再交给 summarize。

weather/report.py
    使用 from .readings import Measurement。
    接收读数，交回摘要文字。

weather/readings.py
    定义 Measurement 的字段和含义。


从文件的依赖来看，report 需要认识 Measurement，而 readings 无需导入 report。如果发现两边互相导入，可以先检查其中一个模块是否包办了两项职责。若双方只共享一个记录类型，把记录放在独立模块中，两个模块都可以沿同一方向导入它。


在模块边界保留可以测试的能力


模块的职责和对象的职责是不同层面。一个模块可以包含几个紧密配合的类和函数。先把接口设计清楚，再按照变化原因划分文件。例如调整摘要格式时，主要修改报告模块。增加一种读数来源时，可以在入口换用另一组对象。只要摘要收到的记录仍符合约定，已有的摘要测试仍可复用。

        2.1 找到活动时，把学号交给该对象办理登记。
        2.2 查不到时，生成“活动不存在”的回执。

参考解答
第一条回执变为“活动不存在”。第二条仍然“通过”。博物馆实例仍存在，目录无法按 museum 找到它，因此名单为空。实验室的名单为 ("S01",)。
not activity 会把长度为零的活动判为假。首次登记无法发生，两场活动都保持为空。
第三个 Draft 用工厂取得新列表。第一份仍有“核对温度”，第二份仍为空。
