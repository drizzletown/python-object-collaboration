对象协作的流程控制

用条件和循环安排协作步骤，按顺序处理报名请求并解释每一条回执。

3.1 一批报名请求怎样逐条处理

第 2 章已经选好保存活动配置和名单的容器。现在活动开放报名，程序收到一批有先后顺序的学号。组织者需要为每条请求给出回执，也需要知道整批处理完后谁进入了名单。

  • 输入是一场容量为 2 的活动、一份空名单，以及依次到达的请求 S01、空白、S02、S03、S01。
  • 处理时先去掉学号首尾空白，再依次检查空学号、重复、满员。满足登记条件时才更新名单。
  • 输出应有五条回执。最后一次请求到达时，名单既已满又包含 S01，按本活动的规则应回执“重复”。

这个任务需要两类安排。一类决定一条请求走哪条路，另一类决定同一组步骤对哪些对象重复执行。先分别学习 Python 怎样表达这两类安排。

3.2 用条件选择执行路径

条件的真值与代码块

if 后面的条件可以是比较结果，也可以直接是对象。空字符串、空容器、数值零、None 和 False 的真值都为假。例如，if not text 对空字符串成立。冒号后缩进的语句属于这个分支，退回原来的缩进就离开分支。教材统一用四个空格表示一级缩进。

独立判断与互斥分支

写法执行规则适合的任务
单个 if条件成立时执行该块需要时追加一条提示
多个并列的 if各自判断，多个条件可以同时成立分别检查多项指标
if / elif / else从上往下检查，只执行首个成立的分支。前面都不成立时执行可选的 else按阈值选择一个级别
嵌套的 if外层分支执行后才检查内层条件先确认有数据，再检查取值

3.3 用循环安排重复


用 for 逐项处理可迭代对象


for 从可迭代对象中逐项取得值，每一轮把当前值绑定到循环变量。列表、元组、字符串、字典和集合都可以遍历。遍历字典时默认得到键，用 items() 可以同时取得键和值。空容器不会执行循环体。


工具依次提供什么使用场景
range(start, stop, step)从起点按步长取整数，不包含终点重复固定次数或按间隔取数
enumerate(values, start=1)序号与当前值组成的二元组给记录编号
zip(left, right)从两组数据各取一项组成二元组把名称与测量值配对
mapping.items()键和值组成的二元组同时读取字典的两个字段

3.5 回到案例 批量处理报名


用 for 按到达顺序取请求。空学号在清理后立即回执，并用 continue 进入下一轮。其余请求通过一组互斥分支确定回执，只有“通过”分支写入名单。每轮结束后都应满足两条规则，已登记的学号互不重复，人数不超过容量。这样的条件称为不变式。

4S03满员S01、S02
5S01重复S01、S02


对照表格核对每一步。第 4、5 步都发生在满员之后，回执却不同，因为第 5 步先满足了重复条件。名单及余量由各轮的更新逐步得出。


练习


先把容量改成 0，预测五条回执和最终名单，再运行核对。恢复容量为 2 后，调换重复与满员判断的顺序，找出第一条发生变化的回执。


参考解答
容量为 0 时，五条回执依次为“满员、空学号、满员、满员、满员”，名单为空。
恢复容量 2 后，调换顺序会使第 5 条从“重复”变成“满员”。此前第 4 条学号是新学号，两种顺序都返回“满员”。
