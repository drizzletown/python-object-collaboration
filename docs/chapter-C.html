C.2 一些常用写法的区别

容易混淆的写法用哪一个问题区分
a == b 和 a is b值是否相等，或两处是否引用同一个对象
x is None 和 not x是否缺失，或真值是否为假
append() 和 extend()添加一个对象，或逐项加入多个对象
sorted(values) 和 values.sort()取得新的排序结果，或在原列表上排序
d[key]、d.get(key)、d.setdefault(key, value)读取必需的键、读取可缺失的键，或缺失时写入
a = b 和 b.copy()建立共享引用，或创建一个浅副本
break 和 continue退出所在循环，或跳过当前这一轮
print(result) 和 return result显示结果，或交给调用者继续使用
json.load() 和 json.loads()从打开的文件读取，或从文字中解析
write() 和 Path.replace()写入打开的流，或用一个完整文件替换目标

C.3 根据异常查找输入与调用

异常典型例子先检查什么
SyntaxError分支标题漏冒号错误位置前后的语法
NameError读取未绑定的名字拼写、定义位置、作用域
TypeError字符串与整数直接相加运算需要的对象类型或调用方式
ValueErrorint("四十二")内容能否转换，取值是否满足约定
KeyError读取字典里没有的键是否允许缺键及默认行为
IndexError读取超出范围的下标长度、起始位置和结束条件
AttributeError对象没有要调用的方法当前对象类型与公开接口
FileNotFoundError路径找不到文件目标位置，以及是否允许首次创建
UnicodeDecodeError用不合适的编码读取文本实际编码与读写时的约定
JSONDecodeErrorJSON 文本没有闭合是否读到了完整且合法的内容

遇到错误时先找出最小输入，再看异常类型和回溯。能读到数据后还要检查它的含义。例如 JSON 能解析出一份活动数据，容量、名单和学号仍要按规则验证。第 7 章 第 8 章
