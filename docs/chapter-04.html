第三视角 函数与协作封装

用函数接口描述一项能力，分别验证单次登记、批量处理和回执生成。

4.1 为登记函数写契约

第 3 章的一段循环负责清理输入、判断资格、登记和输出。如果以后还要在另一份名单上执行同样的登记，就需要把核心处理定义为函数。先约定 register 的输入为学号文本、现有名单和非负容量。返回回执字符串。仅在通过时修改传入名单。调用方决定怎样显示回执。这份约定说明函数接收什么、返回什么、改变什么，是可以测试的契约。

def 定义函数，形参在调用时绑定到实参对象。传入可变字典时，修改字典的内容可以被调用方观察到。把形参重新赋值为另一个字典只会改变函数内部的绑定。return 结束调用并交出结果，省略 return 时结果为 None。

4.2 作用域与函数对象
